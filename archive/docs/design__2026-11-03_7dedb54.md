# iMac風 一体型ゲーミングPC 設計書 (初稿)

目標: 最新iMac(M4, 24")相当以上の性能 + ゲーム可 / 内部は市販品 / 外観はiMac風の一体型。
注: 型番・価格・互換性は設計時点の想定。**発注前に必ず最新仕様を確認**してください。

## 1. 基本方針
- ディスプレイ: 27インチ 4K(3840x2160) IPS 市販パネル + 市販ドライバ基板(eDP/HDMI)。iMac 24の4.5Kパネルは単体入手が難しいため。
- 本体: 前面スラブ(薄型14mm) + 背面下部のサーマルポッド(合計46mm)。熱の大きい部品をポッドに集約し、スラブを薄く保つ。
- スタンド: iMac 24風の一枚アルミアーム。
- 外装: アルミ削り出し or 板金+アルマイト、前面ガラス(AGフィルム任意)。

## 2. 部品案 (市販品)
| 区分 | 候補 | 理由 |
|---|---|---|
| 本体基板 | AMD Ryzen AI Max+ 395搭載のMini-ITX級ボード(例: Framework Desktop Mainboard) | iGPU(Radeon 8060S)でFHD~QHDゲーム可、M4 Pro級の統合性能。ソルダードLPDDR5Xでメモリ薄型 |
| ストレージ | M.2 2280 NVMe SSD 2TB | 基板上スロット |
| 電源 | 外付けACアダプタ+DC入力、または薄型Flex ATX | 内部発熱と厚みを削減。基板の電源仕様は要確認 |
| 冷却 | 120mm薄型ファン(厚15~25mm) + 銅ヒートパイプ + アルミフィン | ポッド内。下吸気→上排気 |
| ディスプレイ | 27" 4K IPSパネル + ドライバ基板 | 要:eDP対応/同梱ケーブル長 |
| スピーカー/カメラ/マイク | 市販USBウェブカメラ基板、小型スピーカーユニット | 上ベゼル/チンに内蔵 |
| Wi-Fi/BT | M.2 Wi-Fi 7カード | ボード搭載品に依存 |

性能目安: 統合GPUのため重い3Dタイトルは設定を下げる前提。より高いGPU性能が必要なら、ポッドを太く(70mm以上)してロープロファイル/ノートPC系dGPUを検討。

## 3. 寸法 (cad/imac_like_pc.scad に反映)
- パネル有効表示: 596.7 x 335.7 mm
- 前面: 約 621 x 389 mm (ベゼル12mm, チン42mm)
- 前面スラブ厚 14mm / 背面ポッド 幅561 x 高200 x 深さ+32mm (合計46mm)
- 重さ目標: 8kg前後

## 4. 熱設計メモ
- 想定発熱: 基板最大 ~120W + パネル ~30W。
- 吸気: ポッド下面スリット、排気: ポッド上面スリット(ガラス面側へ熱を流さない)。
- パネル背面とポッドの間に断熱材/空気層を確保。
- 設計後はファン曲線と通風抵抗で実測検証が必要。

## 5. 次のステップ
1. 採用ボードの実寸(取付穴・I/O位置・高さ)を取得し、scadに内部部品を追加。
2. パネルの型番を確定し、背面ブラケットを設計。
3. 筐体の製作方法(CNC/板金)と予算を決定。
