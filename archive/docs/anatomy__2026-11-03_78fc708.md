# iMac 24インチ 部位と配置

図: `concept/imac_anatomy.svg`(再生成: `python3 tools/gen_anatomy.py`)。緑=確定(公式 or 独立5件以上一致)、橙=未確定。
内部配置の根拠は **M1の分解記事**(M4/M6の分解は未発見)。外観はApple公式画像でM1〜M6が共通。

## 公式の部品名 (Apple 分解修理資料 / 部品表)
ディスプレイ / ディスプレイバックライト・フレックス / マイク・フレックス / バッテリーボード / 高速・低速フレックス / オーディオボード / カメラ+eDPフレックス / USB-Cボード(左右、スピーカークリップ付きカウリング) / アダプタボード / Wi-Fiアンテナ / Wi-Fi・Bluetoothアンテナ / ロジックボード+カバー(EMIシールド) / ファン(左右ペア) / 筐体(Housing) / フランジ / スタンド / VESAマウントアダプタ。外付け: 143W電源アダプタ(Ethernet付き)。

## 配置まとめ
- **上端**: 12MPカメラ+左右にマイク孔(公式画像)。ディスプレイ基板は上部ストリップ(4件、未確定)。
- **ディスプレイ背後**: ほぼ空洞で、大きな薄い金属プレート2枚(6件確定)。用途は未確定。
- **チン(画面下の淡色帯)**: 小型ロジックボード(MacBook Air級), 左右のファン2基, 銅ヒートパイプ+短いヒートシンク2枚(上位構成)。スピーカー/USB-Cボードも付近(位置は推定)。
- **前面**: 色付きチンを含む一枚ガラス。接着で筐体に固定(分解はディスプレイ側から)。
- **背面**: Appleロゴ(アンテナの電波経路)、左下に縦スロット4つ(USB-C)、中央下にスタンド。スタンド背面にマグネット式電源コネクタの凹み。
- **スタンド**: アルミ一枚板。上端フランジで本体背面に接合、側面にヒンジ(チルト)。VESAは購入時選択(後付け不可)。
- **側面**: 厚さ約11.5mm、下部に3.5mmヘッドホンジャック(薄さのため横向き)。

## 本機設計への含意
- iMacはチン内に小型基板+ファン2基で、ディスプレイ背後は空洞。本機は市販ITX+GPUの都合で背面ポッドに集約(70mm厚)。
- 実機に倣い、**4つの縦スロット風I/O、スタンド背面の電源凹み、チルト用ヒンジ**を外観に取り入れる余地あり(現モデルはスロットのみ)。
