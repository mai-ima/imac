# 06 指挟み保護(蛇腹ブーツ)
> 状態: 設計値(PRELIMINARY・未試作)。数値は model/spec.json・model/balance.json と tools/ の計算から自動埋め込み。未確認事項は末尾の表(U台帳 docs/unverified-tracker.md)。

## 1. 危険源
チルトで、頭部(スラブ下縁・ヒンジブロック)とネックカバー上端のすき間が動的に変わる。EN 349 の考え方では、指が入る 4〜25mm のすき間が閉じていく状況が危険。さらにネック内部にはレバー・ばね座(最大670N/本)がある。
## 2. 設計
**ゴム蛇腹ブーツ**で頭部側(ヒンジブロック下面)とネックカバー上端(y=-34)の間を全周塞ぎ、指も異物も入らない閉じた空間にする。
| 項目 | 値 |
|---|---|
| 材質 | ゴム蛇腹ブーツ(シリコーン, UL94 V-0) |
| 山数 | 10 |
| 伸縮範囲 | 22〜70mm(伸縮比≈3.2:1) |
| せん断吸収 | ±8mm(ヒンジ回転で上下の取付面が相対的にずれる) |
| 取付 | 上: ヒンジブロック下面のフランジ(M3×小ねじ+押さえ板)。下: ネックカバー上端の溝(リップ嵌合+押さえ) |
| 交換 | 工具1本。損傷時は交換(整備L2) |
## 3. すき間の変化(チルト別。スラブ下縁中央-カバー上端, 設計式)
| チルト[°] | すき間[mm] |
|---|---|
| -15 | 22.7 |
| -10 | 26.3 |
| +0 | 34.0 |
| +10 | 42.0 |
| +20 | 50.0 |
| +30 | 57.8 |
| +40 | 65.3 |

`tools/motion_check.py` が全角度のすき間を計算し、ブーツ伸縮範囲(22〜70mm)に収まることをゲート化している(範囲外ならNG)。
## 4. 要求・試験
- 難燃 UL94 V-0 相当、耐オゾン、低温(−10℃)で柔軟性維持。
- 伸縮寿命: 25,000回(チルト往復+首振り)。山の折れ癖・割れの確認。
- 指進入試験: IEC/EN の試験指(Ø12・Ø5 のプローブ)がブーツ内側に届かないこと。
