# 04 背面ドームの着脱機構(ラッチ・フック・位置決め・磁石・EMIガスケット)
> 状態: 設計値(PRELIMINARY・未試作)。数値は model/spec.json・model/balance.json と tools/ の計算から自動埋め込み。未確認事項は末尾の表(U台帳 docs/unverified-tracker.md)。

## 1. 目的
ユーザーが工具1本(T10)で背面ドーム(アルミ外装, 約1.5kg)を外し、内部へアクセスできること。ドームは外観部品であり、**電気的・構造的な保持はラッチ+フック**、磁石は補助(アルミは非磁性のため相手は鋼板ストライク)。
## 2. 構成(CP-07/CP-08/CP-09)
| 要素 | 仕様 |
|---|---|
| 上辺フック | 掛け爪×6(ドーム一体)。ドームを上へ3mmスライドして掛ける。ねじ無し |
| 下辺ラッチ | 1/4回転ラッチ×6(下面の凹み内、T10)。1点保持90N=合計540N、回転トルク0.08〜0.18N·m |
| 位置決めピン | Ø4×2(非対称配置で誤組立防止) |
| 補助磁石 | N52 Ø8×3、12個(局所ボスt4.2に厚み3.1のポケット。残肉1.1mm → `tools/dfm_check.py`) |
| EMIガスケット | 導電ファブリックオーバーフォーム 3.0mm、圧縮33%、周長約1947mm。**低閉合力品(0.098N/mm@圧縮33%, spec.dome_seal)を指定**: 公称156N/最大225N(圧縮±8.3%)。溝は縁フランジt4.0に深さ1.5(残肉2.5) |
## 3. 力のつり合い
ガスケット反力(最大225N)を、下辺ラッチ6点(合計540N)と上辺フック6点で受ける。設計条件: ラッチ容量 ≧ 最大反力×1.5(337N)。旧案(0.175N/mm=340N, ラッチ360N)は圧縮公差で反力が490Nに達して**閉まらない**ため、低閉合力ガスケットとラッチ強化に変更した(`tools/fit_tolerance.py`)。
## 4. 着脱手順
外す: 下面の凹みからT10で6点を1/4回転 → ドームを3mm上へスライドしてフックを外す → 後方へ引く。付ける: 逆順。位置決めピン2本+フックで位置が決まる(再現精度はピンはめあい0.004〜0.024mmだが、ドーム外形公差±0.3・平面度0.3が支配的。**±0.1mmは保証しない**)。
## 5. 故障モード
| 故障 | 影響 | 対策 |
|---|---|---|
| ガスケットの圧縮永久歪み | EMI/閉合力低下(下限78N) | 圧縮30%以下、交換可能、歪み≦15% |
| ラッチ緩み | ドームがずれる/異音 | 戻り止め付き規格ラッチ、ピン+フックで位置保持 |
| ドーム落下(上辺フック不良) | 破損・負傷 | フックを6点、掛け代≧3mm |
| ドーム縁の接地不良 | EMI/感電リスク | 接地ストラップ×2(CP-18)、縁の導電面をマスキング(アルマイト非導通部を避ける) |
## 6. 未確認
