## 1. 荷重経路
```
頭部(15.4kg) → ヒンジブロック → ヒンジ軸Ø10 → 摩擦ヒンジ/軸ボス(r11) → 側板(t6) → ネック基台 t8(M5×4) → ロータ板Ø144 → 軸受内輪 → 外輪 → ステータ板 → 足
バランサ: ばね(スタンド側アンカー=側板間ブリッジ) ⇄ 尾部レバー(軸) の力は軸・側板内で閉じ、基台へは差分のみ伝わる
```

## 3. ストッパ(尾部レバー側縁が当たる)
−15°側: レバー側縁 z=−(50·sin15°+7·cos15°)=約−19.7 → パッド面 −19.2(圧縮0.5mm)。+40°側: z=50·sin40°+7·cos40°=約37.5 → パッド面 36.5(圧縮1.0mm)。パッドはゴム(厚≈2mm)、押し荷重の受けは前カバー/タイプレート(t6)。

## 5. 組立順序
1. ステータ→足(M6×4)。2. 軸受(外輪をステータへM5×6)→摩擦リング+波ばね→ロータ(内輪へM5×6皿)。3. ネック基台→ロータ(M5×4)。4. 側板+タイプレート+カバーを基台へ。5. 摩擦ヒンジ・軸・レバー・ばねを組み、調整(01参照)。6. 頭部を掛け、蛇腹ブーツを取付。
