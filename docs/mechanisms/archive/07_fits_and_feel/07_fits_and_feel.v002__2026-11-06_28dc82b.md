# 07 はめあい・操作感の許容窓(「ゆるゆる」でも「硬すぎ」でもない)
> 状態: 設計値(PRELIMINARY・未試作)。数値は model/spec.json・model/balance.json と tools/ の計算から自動埋め込み。未確認事項は末尾の表(U台帳 docs/unverified-tracker.md)。

## 1. 考え方
各インタフェース(ピン-穴、軸-穴、摩擦、ばね、ガスケット、ラッチ)の公差を**最悪ケース**で振り、遊び・操作力・保持力が許容窓に入るかを判定する。窓の下側=緩すぎ(ガタ・滑り・保持不足)、上側=硬すぎ(閉まらない・動かない・操作力超過)。窓の端に近い(余裕小)ものはWARNとして記録する。

## 3. 窓の根拠
| 項目 | 窓 | 根拠 |
|---|---|---|
| 首振り摩擦 | 1.0〜3.0N·m | 下限=画面を軽く触って回らない、上限=画面端の操作力≦20N(0.31m) |
| チルト保持/操作 | 保持≧最悪残差、操作≦20N | 片手で上端を動かせ、任意角度で止まる |
| ドーム閉合 | ラッチ容量 ≧ 最大反力×1.5 | ガスケット反力は圧縮±8.3%で最大1.44倍。旧設計(340N, ラッチ360N)は閉まらないため変更 |
| ラッチ回転トルク | 0.05〜0.5N·m | T10を手で回せ、振動で戻らない |
| 吊りピン隙間 | 0.05〜0.20mm | 掛けられる/ガタつかない |
| 位置決めピン | 0〜0.03mm | 再組立の位置再現±0.1mm |
| ヒンジ軸隙間 | 0〜0.04mm | 画面上端でのカタつき(隙間×約20倍に拡大) |

## 4. 調整・実測で確定する項目(UNVERIFIED)
摩擦リング/摩擦ヒンジの実トルク(μ・温度・経年)、ばね荷重、ガスケット線荷重(圧縮-荷重曲線)、ラッチの引き込み力。**試作で実測し、窓から外れたら調整機構(波ばね予圧、調整ねじ、ガスケット材質)で追い込む**。
