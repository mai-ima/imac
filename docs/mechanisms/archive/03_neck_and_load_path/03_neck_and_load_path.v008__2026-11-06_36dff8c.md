## 3. ストッパ(尾部レバー側縁が当たる)
−15°側: レバー側縁の角 z=−(34·sin15°+7·cos15°)=約−15.6 → パッド近面 −15.1(圧縮0.5mm)。+40°側: z=34·sin40°+7·cos40°=約27.2 → パッド近面 26.2(圧縮1mm)。パッドは厚6mmのウレタン/ゴム(衝撃時は厚みの50%まで圧縮可)、押し荷重の受けは前カバー/タイプレート(t6)。

## 5. 組立順序
1. ステータ→足(M6×4)。2. 軸受(外輪をステータへM5×6)→摩擦リング+波ばね→ロータ(内輪へM5×6皿)。3. ネック基台→ロータ(M5×4)。4. 側板+タイプレート+カバーを基台へ。5. 摩擦ヒンジ・軸・レバー・ばねを組み、調整(01参照)。6. 頭部を掛け、蛇腹ブーツを取付。
