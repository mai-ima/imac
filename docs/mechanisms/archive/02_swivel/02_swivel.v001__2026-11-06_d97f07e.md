# 02 左右首振り機構(クロスローラ軸受+摩擦リング+角度ストッパ)
> 状態: 設計値(PRELIMINARY・未試作)。数値は model/spec.json・model/balance.json と tools/ の計算から自動埋め込み。未確認事項は末尾の表(U台帳 docs/unverified-tracker.md)。

## 1. 要求
| 要求 | 値 |
|---|---|
| 範囲 | 左右 ±60°(計120°) |
| 操作力 | 画面端(軸から0.31m)で≦20N → 保持トルク 1.6N·m → 5.2N |
| 保持 | 任意角度で止まる(摩擦リング) |
| 配線 | 内部ケーブルは通さない(ACコードは背面インレットに外付け)。PEのみ編組ループで跨ぐ |
| 転倒 | チルト×首振りの全格子で前25N/後20N/横30N以上、10°傾斜で転倒しない |

## 2. 構成(下から上へ、軸=足の中心線、高さ 25mm)
| 層 | 部品 | 仕様 |
|---|---|---|
| 足 | CP-10 | 360×310×12、バラスト3.5kg内蔵 |
| ステータ板 | CP-20 | A5052 Ø150×t6、外輪側 M5×6(PCD90)、足へM6×4、ストッパポストØ10 ×2(r78, ±67.4°) |
| 摩擦リング | PTFE/ゴム系 | 内輪下面とステータ上面の間(r35)、波ばねで予圧 |
| 軸受 | クロスローラ(スリューリング) | OD100/ID60×12(型番 U50)。外輪=静止、内輪=回転 |
| ロータ板 | CP-21 | A5052 Ø144×t6、内輪側 M5×6(PCD70)皿頭(ネック基台と干渉しない)、ストッパタブ(SUS, 同じ高さ) |
| ネック基台 | CP-22a | t8 124×72、M5×4でロータへ |

## 3. 摩擦保持トルクの設計
T = μ·F·r_m。r_m=35mm、μ=0.1(PTFE)〜0.15(ゴム系)のとき、必要な波ばね予圧 F = T/(μ·r_m) = 305〜457N。経年(摩耗・クリープ)で下がるため、波ばねの予圧余裕を確保し、予圧は整備時に調整可能にする(未設計: U52)。

## 4. 軸受の要求と選定条件(`tools/swivel_calc.py`)
```
頭部 15.4kg / 最大チルト+40°での重心水平オフセット 119mm / 軸受面から画面上端 475mm
軸力 151N / 静モーメント 18.0N·m / 操作押し荷重50N→23.8N·m / 衝撃(2G) 35.9N·m
要求: 軸受の許容モーメント ≧ 63N·m(安全率1.5, 静+操作), 許容軸力 ≧ 454N(3倍), ストッパ衝撃 etc.
首振り操作力(画面端 0.31m): 5.2N(目標≦20N) → [OK]
ストッパ衝突エネルギー(0.25rad/s): 17.0mJ(ゴムポストで十分小さい想定。実測U52)
軸受定格: 未設定 → UNVERIFIED(型番選定U50: 許容モーメント≧要求を満たす市販クロスローラ/スリューリングを選ぶこと)
```
選定条件: 許容モーメント ≧ 要求(安全率1.5, 静荷重+50N押し)、許容軸力 ≧ 軸力の3倍、OD≦100mm・高さ≦12mm、回転摩擦トルクは摩擦リング保持の1/5以下。**型番は未選定(U50)**で、合否は未確認。

## 5. 角度ストッパ
ステータ上のゴムポスト(鋼芯Ø10, 半径78mm)にロータ縁のタブが当たる。タブ半幅5+ポスト半径5 の接触角補正で、ポスト位置は ±67.4° とし、実効 ±60°。50N押しでポスト1本が受ける力は約263N(strength_check: ポストØ10の曲げ ≦ 許容)。

## 6. PE接地(保護接地)の跨ぎ
ネック(回転側)→足(固定側)に編組(6mm²)を**ループ**で配線。長さ170mm、可動範囲の最大端間距離 約69mm+余長15mm を満たす(motion_check で検査)。接地導通≦0.1Ω(各部〜PE)は実測が必要(grounding-spec.md)。

## 8. 故障モード
| 故障 | 影響 | 対策 |
|---|---|---|
| 摩擦リングの摩耗 | 保持不足(画面が回る) | 波ばね予圧の調整、リング交換 |
| ストッパ破損 | 範囲超過→PE編組の引張 | ポストを鋼芯化、編組に余長 |
| 軸受のがた(予圧抜け) | 画面のぐらつき | クロスローラの予圧指定 |
| 指挟み(足とロータ間) | 負傷 | ロータ縁と足上面のすき間≧25mm または カバー(未設計 U53) |
