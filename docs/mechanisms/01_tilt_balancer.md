# 01 チルトバランサ(カム+ローラ従動子+ダイスプリング+摩擦ヒンジ)
> 状態: 設計値(PRELIMINARY・未試作)。数値は model/spec.json・model/balance.json と tools/ の計算から自動埋め込み。未確認事項は末尾の表(U台帳 docs/unverified-tracker.md)。

> **R9T-001(2026-11-06)で方式を変更**: 旧方式(尾部レバー先端と下のアンカーを圧縮ばねで結ぶ)は、エネルギー法で再計算すると転倒方向のトルクになり成立しなかった。以下はカム方式の設計。

| 要求 | 値 | 根拠 |

| チルト範囲 | -15°〜+40°(計55°) | ユーザー要望(旧 −5〜+25° から拡大) |
| 画面上端での操作力 | ≦20N | 片手操作。(最大摩擦+調整後の最悪残差)/0.41m で評価(ユーザー原要求の20Nへ復帰) |

| 単一故障 | ばね1本折損でも**減速して端に到達し、破損しない** | 摩擦ヒンジ+ゴムパッド(厚6mm)+左右2系統+案内ロッド |

## 2. 原理(初心者向け)
頭部(約15kg)の重心はヒンジ軸の約185mm上にある。傾けると位置エネルギーが U_g=m·g·dy·(1−cos a) だけ増え、「倒れようとする力のモーメント」は τ=m·g·dy·sin(a)(+40°で約18N·m)になる。
**ばねに同じだけエネルギーを蓄えさせれば釣り合う**。頭部側に取り付けたカム板が回ると、軸の真下の直線上にあるローラが押し下げられてダイスプリングが圧縮される。ローラ中心の軸からの距離 ρ(a) を F0·(ρ−ρ0)+k/2·(ρ−ρ0)² = ∫τ da となるように設計すれば、**任意の角度で残差がほぼ0**になる(最悪でも荷重・重心の公差分だけ)。残りの小さな差は摩擦ヒンジが保持する。

旧方式(尾部レバー+下のアンカーの圧縮ばね)は、傾くほどピン間距離が伸びてばねが**緩む**ためエネルギーが減り、転倒を助ける向きのトルクになる(圧縮ばねを軸の同じ側で使うと不安定)。独立再計算で確認し廃止した。

- 残差の公称値はカム形状を解析的に求めているため0になる(自明)。意味があるのは**公差込みの最悪残差**と、経年後の摩擦で保持できるか(ゲート)。
- 未調整(荷重±10%・重心±10mm)の最悪残差は大きい → **ばね座シムによる工場調整が前提**(調整後±3%)。

## 5. 組立・調整手順
1. 頭部(ばね無し)を治具に載せ、ヒンジ軸の重量モーメントを実測(0°での力×0.41m、または重量+重心)。
2. ばね座に公称シムを入れてばねを組み、0°での釣り合いを確認。
3. −15°/0°/+20°/+40°で上端の保持力をばねばかりで測り、規定帯(残差±公差)に入るまでシムを増減。
4. トルクペイントで封印。以後の再調整は整備者(L3)のみ。

## 6. 故障モード(FMEA抜粋)
| 故障 | 影響 | 対策 | 検出 |
|---|---|---|---|
| ばね1本折損 | 復元トルクが半減→端へ動く(strength_checkの落下エネルギー参照) | 左右2系統+案内ロッド+ストッパ(ゴム厚6mm)+摩擦ヒンジ | 異音/保持低下 |
| ばね力の経年低下(クリープ) | 保持不足 | シムで再調整、定期点検(1年) | 保持力測定 |
| 摩擦ヒンジの摩耗 | 保持不足 | 余裕(経年後の最小摩擦≧最悪残差)、交換可能 | 保持力測定 |
| カム面/ローラの摩耗・圧痕 | トルク曲線のずれ、ガタ | 焼入れローラ+SUS304カム(表面硬化)、潤滑(U51) | 保持力測定 |
| 指の挟み込み | 負傷 | 蛇腹ブーツ(06_pinch_guard.md) | - |
