# 01 チルトバランサ(ダイスプリング+尾部レバー+摩擦ヒンジ)
> 状態: 設計値(PRELIMINARY・未試作)。数値は model/spec.json・model/balance.json と tools/ の計算から自動埋め込み。未確認事項は末尾の表(U台帳 docs/unverified-tracker.md)。

## 1. 目的と要求
| 要求 | 値 | 根拠 |
|---|---|---|
| チルト範囲 | -15°〜+40°(計55°) | ユーザー要望(旧 −5〜+25° から拡大) |
| 画面上端での操作力 | ≦20N | 片手操作。(最大摩擦+公称残差)/0.41m で評価 |
| 任意角度で保持 | 最悪残差 ≦ 最小摩擦 | 荷重±3%・重心±3mm(調整後) |
| 耐久 | 25,000回 | 一般的な机上機器の目安(要試験) |
| 単一故障 | ばね1本折損でも**減速して端に到達し、破損しない** | 摩擦ヒンジ+ゴムパッド(厚6mm)+左右2系統。落下エネルギー約0.95J、ストッパ衝突でレバー応力33MPa(strength_check)。**ただし頭部は端まで動く**(静止保持はできない) |

## 2. 原理(初心者向け)
頭部(約15kg)の重心はヒンジ軸の約185mm上にある。傾けると「倒れようとする力のモーメント」τ=m·g·dy·sin(a) が増える(+40°で約18N·m)。
軸から下へ25mm伸びる**尾部レバー**の先端を、スタンド側(軸から下へ65mm)に固定した**ダイスプリング**が押すと、ばね力×てこの腕が角度の正弦に比例して変わり、重力モーメントの形とほぼ一致する(アングルポイズランプと同じ原理)。残りを**対称摩擦ヒンジ**(合計4.1N·m, 公差±8%)で保持する。

- ばね軸は −19°〜+9° 揺動するため、**両端を揺動ピン支持**したテレスコ式ガイド(ロッド+筒)とする。座屈防止のためガイドロッド径はばね内径より小さく(遊びあり)。
- 未調整(荷重±10%・重心±10mm)の最悪残差は大きく、保持と操作が両立しない → **荷重調整ねじによる工場調整が前提**。

## 5. 組立・調整手順
1. 頭部(ばね無し)を治具に載せ、ヒンジ軸の重量モーメントを実測(0°での力×0.41m、または重量+重心)。
2. 調整ねじを緩めた状態でばねを取り付け、0°での釣り合いを確認。
3. −15°/0°/+20°/+40°で上端の保持力をばねばかりで測り、規定帯(上表の残差±公差)に入るまで調整ねじを回す。
4. ロックナットを締め、トルクペイント。以後の再調整は整備者(L3)のみ。

## 6. 故障モード(FMEA抜粋)
| 故障 | 影響 | 対策 | 検出 |
|---|---|---|---|
| ばね1本折損 | 釣り合い半減→+40°付近の残差≒10N·m>最小摩擦で頭部が端へ動く(落下E≒0.95J, ω≈1.6rad/s) | 左右2系統+ストッパ(ゴム厚6mm)+摩擦ヒンジで衝突を受け止める(破損しない)。急落そのものは防げない→指挟み保護(06)とユーザー向け注意。ばねは折損しても飛散しないガイド筒内 | 操作力の急変(整備点検) |
| ばね力の経年低下(クリープ) | 保持不足 | 調整ねじで再調整、定期点検(1年) | 保持力測定 |
| 摩擦ヒンジの摩耗 | 保持不足 | 余裕(最小摩擦≧最悪残差)、交換可能 | 保持力測定 |
| レバー/軸の折損 | 急落の恐れ | 応力 ≦ 許容(下表)、キー溝のR確保、疲労は未評価(U51) | - |
| 指の挟み込み | 負傷 | 蛇腹ブーツ(06_pinch_guard.md) | - |
