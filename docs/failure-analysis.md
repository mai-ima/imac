## RPN≥150 (15件) の対応状況
- 安全規格 / PSE/VCCI/電波法未適合(販売する場合): 販売しない/適合性評価を外注
- ヒンジ / チルト保持できず画面が下がる/倒れる: カウンターバランス+対称摩擦ヒンジ併用、金属製ばね保持、機械ストッパ
- EMIガスケット / 陽極酸化層で接地不良: 接触面はマスキング/導電処理(MIL-DTL-5541 Class 3相当)
- AIO / 冷却液の透過減少(経年): 5〜6年保証内で点検、ポンプ温度監視
- AIO ホース / 最小曲げ半径超過によるキンク→流量低下: クリップで曲げ半径規制(公式未確認:U)、短いホース長を使わない
- GPU / 縦置きで自重によりライザー端子に曲げ: 下端のクレードル(ブラケット)で荷重を受ける
- キーホール吊りピン / 衝撃でキーホール縁が塑性変形し脱落: 硬質ブッシュ/t3.0増厚、拘束ネジ2本、輸送時固定
- パネル / 背面からの熱でバックライト温度上昇: 断熱層、トレイとパネル間のエアギャップ、温度実測
- ドーム固定 / ガスケット反発力で磁石が負けて浮く: 低圧縮ガスケット+ラッチ6点以上、磁石は位置決め補助
- AIO ポンプ / ポンプ空運転/気泡: ラジエーター上端>ポンプ(本設計適合)、傾斜での始動試験
- RFアンテナ / 全金属筐体で電波が遮蔽されWi-Fi低下: 樹脂RF窓を背面上部に設け、アンテナを窓の裏へ(未設計→TODO)
- スタンド接合 / M6ネジ緩み/焼付き: ネジロック(中強度)、座金、潤滑、トルク6N·m管理
- 前面ガラス / 熱膨張差でガラス割れ/剥離: 構造用シリコーン接着(厚≥1mm)、クリアランス0.5mm以上
- パネル / COF(下端)破損、バックライト不良: 取付手順でCOFを押さない、ESD、温度分離(8mm空間)
- GPU / ライザー(PCIe5.0)で信号不良/リンク落ち: PCIe5.0対応品、x16→Gen4固定オプション、BIOS設定
