# 整備マニュアル(Service Manual) v8 — iMac風PC

> **状態: 設計段階の手順書(PRELIMINARY)。** 本書の数値は `model/*.json` から自動生成した設計値で、未承認・未試作・未実測です。所要時間・締付トルクのうち出典欄が「UNVERIFIED」のものは、実機試験で確定するまで確定値として扱わないでください。
> **生成物です。** 手で直さず `tools/gen_manuals.py`(テンプレート)か `model/*.json` を直して `python3 tools/gen_manuals.py` で再生成します。設計根拠は [service-mechanisms.md](service-mechanisms.md)、組立は [build-guide.md](build-guide.md)、特殊機構は [mechanisms/README.md](mechanisms/README.md)。旧版は `docs/archive/service-manual/`。

## 0. 本書の使い方

### 0.3 手順の書式
各手順は「前提 → 所要時間 → 工具 → 部品/番号 → 図 → 番号付き手順(1手順=1動作) → 復旧チェックリスト → トラブルシュート」の順です。トルクは `model/*.json` の値、無いものは UNVERIFIED と明記します。

## 1. 安全上の注意

**警告** 感電: 作業前に必ず(1) 電源OFF、(2) ACコードをインレットとコンセントの両方から抜く、(3) **5分待つ**(PSUのコンデンサ放電。待ち時間は一般的な目安で、PSU公式値は UNVERIFIED=U47)。
**警告** 質量: 本体は約22.5kg(頭部15.4+スタンド7.1。いずれも `tools/massmodel.py` の推定で未実測=U25)。持ち上げ・運搬は**2人**。1人で作業するときは本体を最大チルトにして足を机に置いたまま行い、持ち上げない。
**警告** 蓄勢ばね: チルトバランサのダイスプリング2本は常時 1350N(0°で合計、1本675N、最大 992.2N/本)で圧縮されています。**ヒンジブロックを背板から外す作業(手順H)とバランサの分解(手順K)は、ばね保持治具(未設計=UNVERIFIED)ができるまで実施しないこと。**
**警告** 熱傷: 運転直後はポンプ・GPU・PSU・ラジエーターが高温。運転停止後に十分冷ます(冷却時間の規定値は UNVERIFIED。手で触れて確認)。
**注意** 静電気: リストストラップを背板の接地スタッド(M4)または露出金属部に接続して作業する。
**注意** パネル下端のCOF(フレキ基板)を押さない・折らない。
**注意** 前面ガラスは接着構造で、利用者は外せない(手順G)。外装面は柔らかい布の上に置く。
**注意** 接地編組(トレイ↔背板、ドーム↔背板、ネック→足)を外したら、**復旧を必ず確認**(色タグ付き)。陽極酸化皮膜は絶縁です。接地部は皮膜マスク済みの面に歯付座金で締結する([spec/grounding-spec.md](spec/grounding-spec.md))。

## 4. 手順

### 手順A: 背面ドームを外す/付ける(L1)
| 項目 | 内容 |
|---|---|
| 前提 | 電源OFF・ACコード抜き・5分経過(§1)。ドームは外観部品でEMI/接地部品を兼ねる |
| 所要時間 | 約3分(設計見積・未実測。UNVERIFIED) |
| 工具 | T1(T10)、柔らかい作業マット |
| 部品 | ドーム CP-07、下辺ラッチ×6 CP-09、上辺掛け爪フック×6、EMIガスケット CP-08、接地ストラップ×2 CP-18 |
| 図 | 図07、図08(レベルA)、D06 |

**警告** ドーム落下防止: ラッチを全て解除する前にドーム下縁から手を離さない。
**注意** ドーム縁のEMIガスケット(CP-08)を傷つけない・引き伸ばさない。

**外す**
1. 本体を最大チルト(+40°)にする。
2. 本体下面の凹みに T10 を差し込む。
3. 下辺ラッチ(6点のうち1点目)を1/4回転して解除する。
4. 残りの下辺ラッチ(各1点ずつ)を同様に1/4回転して解除する(合計6点)。
5. ドーム下縁を両手で持つ。
6. ドームを**上へ約3mm**スライドして上辺の掛け爪フックを外す。
7. ドームを後方へ引き離す。
8. 接地ストラップ(ドーム↔背板、色タグ付き)を外す。
9. ドームを内側を上にして柔らかい面に置く。
10. 必要ならメッシュフィルタ CP-13(磁石式)を外し、清掃する。

**付ける(逆順)**
11. メッシュフィルタを磁石位置に合わせて戻す。
12. 接地ストラップをドームの接地ラグ(M3)と背板側へ取り付ける(歯付座金、皮膜マスク面)。
13. 位置決めピン2本(非対称)をピン穴に合わせる。
14. ドーム上辺の掛け爪を背板のストライク鋼板に掛ける。
15. ドームを下へ約3mmスライドして掛け爪を掛け切る。
16. 下辺ラッチ6点をT10で1/4回転して締める(1点ずつ)。

**復旧チェックリスト**
- [ ] ラッチ6点すべて施錠(回転トルクの目安 0.08〜0.18N·m: mechanisms/04。出典は設計値で UNVERIFIED=U29)
- [ ] ドーム縁と背板のすき間が全周均一(設計目標 0.5±0.1mm: PRINCIPLES A3)で、ガスケットのはみ出し・浮きが無い
- [ ] 接地ストラップ2本を接続。ドーム縁〜背板接地スタッド間の導通 ≦0.1Ω
- [ ] 外面にネジ・ラベルが露出していない

**トラブルシュート**
| 症状 | 想定原因 | 対処 |
|---|---|---|
| ラッチを締めてもドームが浮く | ガスケットのはみ出し/ずれ、位置決めピン未嵌合 | 全ラッチを緩め、ピンとフックを再度合わせる |
| ラッチが締まらない/硬い | ガスケット反力が過大(239N超)、ガスケット品種違い | 低閉合力品(0.098N/mm)か確認。型番は UNVERIFIED(U30) |
| 走行中に異音(カタカタ) | ラッチ緩み、フックの掛かり不足 | 手順Aを再実施。改善しなければ L2 へ |
| 掛け爪が掛からない | 3mmスライド不足、背板ストライクの変形 | スライド量を確認。変形があれば L3 |

> **UNVERIFIED** 上辺フック6点と、spec.dome_seal が前提とする左右辺の側辺フック×4(各40N)の関係が文書間で食い違っている(MAN-014)。側辺フックがある場合、手順A-6 の「上へ3mm」に加え側辺の掛かりも外す必要がある。確定は図面更新後。

### 手順B: メモリ/SSD/ファン(L1)
| 項目 | 内容 |
|---|---|
| 前提 | 手順Aでドームを外した状態 |
| 所要時間 | 約5分(設計見積・UNVERIFIED) |
| 工具 | T1(T10)、リストストラップ |
| 部品 | DIMM(DDR5、型番 U12)、SSD(Samsung 990 PRO、M.2ドーターカード上)、ケースファン(ARCTIC P12 Pro) |
| 図 | 図09、図10、図13 |

**注意** ホース(H1,H2)とポンプに触れない・引かない(最小曲げ半径は UNVERIFIED=U45)。

**メモリ(DIMM)**
1. リストストラップを接続する。
2. DIMMスロット両端のラッチを外側へ開く。
3. DIMMを垂直に引き抜く。
4. 新しいDIMMのノッチをスロットに合わせて差し込む。
5. 両端のラッチが「カチッ」と閉まるまで押し込む。
6. 復旧後、BIOSでメモリ容量とEXPO設定を確認する(EXPO対応は型番確定後=U12)。

**SSD**
7. M.2ドーターカードのSSD固定部を解除する(固定方式・ポスト位置は UNVERIFIED=U56)。
8. SSDを斜めに引き抜く。
9. 新しいSSDを斜めに挿入し、固定する。
10. BIOSで認識を確認する。

**ファン**
11. ファンのゴムピンを引き抜く。
12. ファンコネクタをハブ(または基板FAN_HDR)から外す。
13. ファンを取り外し、新しいファンを同じ向き(気流方向は図13)で取り付ける。
14. ゴムピンを差し込み、コネクタを接続する(PWM 4pin)。

**復旧チェックリスト**
- [ ] BIOSでメモリ容量・SSD認識
- [ ] ファンが回転し、気流方向が図13と一致
- [ ] ホース・ケーブルがクリップから外れていない(図16)

### 手順C: サービストレイを取り出す/戻す(L2)
| 項目 | 内容 |
|---|---|
| 前提 | 手順A完了。**接地編組の取り外しが含まれる** |
| 所要時間 | 約10分(設計見積・UNVERIFIED) |
| 工具 | T1(T10) |
| 部品 | トレイ CP-06(約6.6kg)、吊りピン×4 CP-04 + SUSブッシュ CP-05、拘束ネジ×2(F5)、アンビリカル CP-17(W5)、接地編組 CP-18 |
| 図 | 図06、図07、図08(レベルC)、D07 |

**警告** トレイは約6.6kg。両手で持つ。ハンドル(上端の折りたたみ線材)を使う。
**注意** 引き出し量は約100mmまで。それ以上引くとアンビリカル(全長380mm、整備余長100mm)を引っ張る。

1. 手順Aでドームを外す。
2. トレイ下辺の拘束ネジ(M3 T10、2本)を T10 で外す。
3. 上端の折りたたみハンドルを起こす。
4. トレイを**12mm持ち上げる**(キーホールの丸穴Ø10.2が吊りピンの頭に合う位置)。
5. トレイを**背面へ約100mm**引く。
6. 番号タグ(W5)を確認し、アンビリカル(eDP/12V/USB)をコネクタのロックを解除して外す。
7. 外したコネクタに保護キャップをする。
8. **接地編組(トレイ↔背板、色タグ付き)をリング端子のネジで外す。**
9. トレイを両手で取り出し、柔らかいマットに置く。

**復旧(逆順)**
10. トレイを背板の近くで保持し、接地編組を接地スタッド(M4)へ締結する(歯付座金、導電コンパウンド)。
11. アンビリカルを番号タグどおりに接続し、ロックを確認する。保護キャップを外す。
12. キーホールの丸穴を吊りピン頭に合わせて押し当て、下へ12mm下げて溝(W6.3)に掛ける。
13. 拘束ネジ2本を T10 で 0.6N·m で締める。

**復旧チェックリスト**
- [ ] **接地編組の復旧**(色タグ一致)。トレイ接地スタッド〜背板接地スタッド間 ≦0.1Ω
- [ ] アンビリカルのロック、ケーブルが挟まれていない(図16の経路)
- [ ] 拘束ネジ2本を 0.6N·m
- [ ] 通電して映像が出る

**トラブルシュート**
| 症状 | 想定原因 | 対処 |
|---|---|---|
| トレイがキーホールに掛からない | 吊りピン頭と丸穴の位置ずれ、キーホール向き(非対称)違い | 向きを確認し、再度合わせる |
| トレイにがたつき | 拘束ネジ未締結/ピンのゆるみ(F4 1.7N·m+ネジロック) | 拘束ネジを締める。ピンのゆるみは L3 |
| 画面が映らない | アンビリカルの外れ/断線、ctrl基板 | コネクタ再接続→W5の導通確認 |
| 電源は入るが画面が暗い | バックライト電源(12V) | W5の12V線とctrl基板を確認 |

### 手順D: GPUの交換(L2)
| 項目 | 内容 |
|---|---|
| 前提 | 手順C完了。トレイを平らな面に置く |
| 所要時間 | 約15分(設計見積・UNVERIFIED) |
| 工具 | T1(T10)、T4 |
| 部品 | GPU(小型2スロット、型番 U46)、ライザー(LINKUP AVA5 系、U09/U60)、GPUクレードル CP-14、12V-2x6ケーブル(W3)、DPケーブル(W7) |
| 図 | 図10、図11a、図11b、図16 |

**注意** ライザーのコネクタに曲げ荷重を掛けない。GPUは下端のクレードル(CP-14)で支持(自重と衝撃)。
**注意** ホース(H1,H2)はGPU下端の下を通る。**動かさない**。

1. 12V-2x6ケーブル(W3)をGPUから外す(ラッチを押しながら)。
2. DPケーブル(W7)をGPUから外す。
3. クレードル(CP-14)のクランプを開く。
4. ライザー側のラッチを解除する。
5. GPUを持ち上げて取り外す。
6. 新しいGPUをライザーに挿入し、ラッチを掛ける。
7. クレードルのクランプを閉じる。
8. W7、W3の順に接続する(W3はコネクタ後方35mmを直線にする)。

**復旧チェックリスト**
- [ ] BIOSでGPU認識とPCIe世代(ライザー互換は U09: 未確認)
- [ ] GPUファン回転、ホースにGPUが触れていない

### 手順E: 電源(PSU)の交換(L2)
| 項目 | 内容 |
|---|---|
| 前提 | 手順C完了。**ACコードを抜き5分経過** |
| 所要時間 | 約15分(設計見積・UNVERIFIED) |
| 工具 | T4、T1 |
| 部品 | PSU(Corsair SF1000、U47)、スタンドオフ(3.0mm)、W1 24p、W2 EPS、W3 12V-2x6、W4 ctrl基板12V、W6 AC(C14→C13) |
| 図 | 図10、図12 |

**警告** PSU交換後もAC側の保護接地(PE)を必ず復旧する(C13ケーブルのPE+筐体二重化=CP-18)。

1. W6(C13)をPSUから外す。
2. W1(24p)をPSUのモジュラー側/基板側から外す。
3. W2(EPS)を外す。
4. W3(12V-2x6)を外す。
5. W4(ctrl基板12V)を外す。
6. PSU固定のM3×4を外す。
7. PSUを取り出す。
8. 新しいPSUを固定(M3×4)し、W1〜W4、W6を逆順で接続する。

**復旧チェックリスト**
- [ ] ケーブル長・経路が [wiring.md](wiring.md) と一致(曲げ半径: 24p/EPS/PCIeは線外径の6倍以上)
- [ ] PSUのPE導通 ≦0.1Ω、通電で起動

### 手順F: CPU・水冷(L2)
| 項目 | 内容 |
|---|---|
| 前提 | 手順C完了 |
| 所要時間 | 約30分(設計見積・UNVERIFIED) |
| 工具 | T1、プラスドライバ(ポンプのばね付きネジ。ねじ頭仕様は ARCTIC 公式図で確認=UNVERIFIED) |
| 部品 | ARCTIC Liquid Freezer III Pro 240(ACFRE00178A非RGB、U33)、ポンプ固定ばね付きM4×4(AM5バックプレート付属)、ラジエーター固定M3×4、サーマルグリス(MX-6) |
| 図 | 図11a、D01 |

**警告** 運転直後は冷却液・ポンプが高温。
**注意** ホース出口はポンプ上面から垂直(U57)。ホースは最小曲げ半径(U45: 40mm仮置き)以上を保つ。

1. ポンプ固定のばね付きネジ4本を、**対角順に少しずつ**緩める。
2. ポンプをCPUから静かに離す(ホースを引かない)。
3. ラジエーター固定M3×4を外す。
4. ホースに余長がある状態で、ラジエーターごと取り出す。
5. CPU(IHS)と冷却板の古いグリスを拭き取る。
6. 新しいグリスを塗る(量は ARCTIC 付属説明書による)。
