# 設計 v6: iMacに近づける / 耐久性 / 整備性

制約の緩和: **ケースの拡張を許可**。ただし「正面の薄さ・色付きチン・一枚板スタンド・ガラス面」というiMacの印象は崩さない。

## 1. iMacに近づけるための形状の再設計
| 項目 | v5まで | v6 |
|---|---|---|
| 正面 | iMac風(白縁の一枚ガラス+色付きチン) | 同じ(変更なし)。比率は公式画像から実測した値 |
| 側面の印象 | 薄いスラブの下に厚い箱(ポッド108mm)が突き出す | **背面ドーム**: 縁は薄く(約18mm+数mm)、中央へ傾斜して最大厚108mm。iMac Pro/旧iMac(2012)の「縁が薄い」印象に近づける |
| 背面 | 箱の上面・背面・側面に角がある | 背面は**連続した曲面のシェル**。ロゴ位置(中央上)・左下のポートの位置関係を実機に合わせる |
| ポート | 下壁から直下に露出 | ドームの下側の傾斜面(後ろ斜め下向き)に配置。実機の「背面左下」に近い |
| スタンド | 一枚板(130→150mm幅) | 同じ。ヒンジは耐久ヒンジ(後述)。ドームの下側(スラブが露出する36mm)に取り付け |
| 色 | 7色 | 同じ。背面は彩度高、スタンド・チンは淡色 |

ドーム外形(`model/spec.json` の `dome`): 左右30mm・下36mm・上28mmの余白、角R50、傾斜の水平距離70mm、縁の内部有効奥行12mm、最大総厚108mm(中央のプラトー)。

### 形状に伴う配置制約
部品の高さ(z)に対し、ドーム縁からの距離 `d` で許される内部奥行は `12 + 75 × min(1, d/70)` mm。背の高い部品(CPUクーラー全高83.6mm)は縁から約67mm以上内側に置く。`tools/fitcheck.py` はこの傾斜を考慮して判定する。

## 2. 整備性(メンテナンス)
- **一体のサービストレイ**: 基板・GPU・電源・ファン・制御基板を、背面から引き出せる**アルミのトレイ**に載せる。背面カバー(ドーム)は**拘束ネジ(落下防止)4本+位置決めピン**で外せ、工具はT10/プラス1種類。
- **ホットスワップ可能な部品**: ケースファンはクイックリリース、ダストフィルタは磁石式で取り外して洗える。SSD・メモリ・GPU・電源・クーラーは標準規格品なので交換可能。
- **ケーブル**: 色分けと番号タグ付きの既製ハーネス。最小曲げ半径を守るクリップ位置を図面に指定。再接続しても誤接続しない(コネクタが規格で嵌合方向を持つ)よう、ハーネス図を作る。
- **前面ガラス**: iMacは接着だが、整備性の面で不利。v6では**周囲のガスケット+非露出の機械固定**を基本案とし、接着(OCA)の場合は交換手順を別途定義する。どちらも未確定の設計判断(要試作)。
- **診断**: 背面ポート近くに電源ボタンとBIOS FlashBackボタン(X870-I)を出す。

## 3. 耐久性
- **材料**: 外装はA5052(板金)、スタンドは6063系の押出/削出し、アルマイト(外装:タイプII、スタンド接触部:硬質)。前面は化学強化ガラス。
- **ヒンジ**: 市販の**定トルクヒンジ**を採用(型番は未選定)。想定荷重(後述の質量推定)と**チルト操作25,000回**を試験条件とする。
- **安定性**: 転倒角を `tools/stability.py` で計算(質量は推定値。実測で更新)。足の奥行147mm・幅は必要に応じて拡大。
- **ゴム足**: 足の裏にシリコン足4点、振動の伝達を抑える。
- **熱**: ファン故障時の過熱保護(BIOSで温度上限、ファン回転検知)。長時間負荷試験の合否基準は温度マージン(CPU Tjmax-10℃以内など)で別途定義。
- **防塵**: 吸気メッシュに磁石式フィルタ。ポート周りはシール材(防塵ブラシ)。
- **輸送**: 梱包時の衝撃を想定し、GPU・クーラーを固定する支持を追加(トレイ側の支柱、GPUブラケット固定)。

## 4. 見落としやすい要素(新たに意識する点)
- **Wi-Fi/Bluetoothのアンテナ**: 全金属の筐体は電波を遮るため、**樹脂(またはガラス)のRF窓**をアンテナ位置に設ける。iMacのロゴ付近が窓になっているのと同じ考え方。X870-IのSMA端子から延長して窓の裏に取り付ける。
- **EMI/静電気**: 板金の継ぎ目に導電ガスケット。接地は電源の保護アース→アルミ筐体に確実に導通。
- **表面温度**: 手が触れる外装面の温度は、規格(IEC 62368-1の接触温度の基準)に収まることを試作で測定。数値は未測定。
- **騒音**: 目標を負荷時35dBA(1m)程度とし、ファン曲線を設計する(未測定)。
- **電源入力**: IEC C14を下面に出し、ケーブルはスタンドの背後に抜ける。ストレインリリーフ。
- **規格・法令**: 個人製作でも、電源・熱・電波の安全は重要。PSE/VCCI等の適合性は未評価(販売する場合は別途必要)。
- **保証**: 純正モニタ分解や改造により、各部品の保証が影響を受ける可能性。
