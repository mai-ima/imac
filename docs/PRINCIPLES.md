# 基本思想・制作思想(不変条件) — 各周で必ず確認する

変更してよいのは「数値・構成・部品」であって、ここに書く思想ではない。設計を直すたびに、この表で逸脱がないか確認する(逸脱したら理由と代替を docs/audit-log.md に記録)。

## A. 製品思想(Apple的デザイン哲学へのオマージュ。詳細は docs/spec/design-philosophy.md の P1〜P11)
1. **単純さ・一つの塊**: 前面は一枚のガラス面、背面は連続したシェル。外面に見える締結具・ロゴ・ラベルは置かない(商標/ロゴは使わない)。
2. **隠された機構**: 固定・調整・ラッチは視線から隠れた位置。操作は下面/内側。ヒンジ/バランサはスタンド内の隠し機構。
3. **均一なすき間・面一・連続曲率**: 継ぎ目0.5±0.1mm、段差≦0.1mm、角Rの統一。
4. **素材に誠実**: アルミ+ガラスが主。塗装で金属を偽装しない。
5. **静かな高性能**: 騒音≦38dBA目標、ファンは主張しない。**性能を制限しない**(CPU/GPUの電力制限に頼らない)。
6. **使う人への敬意**: チルトは片手で滑らかに、どこでも止まる。首振りは軽く止まる。ポート/電源ボタンは手探りで分かる。
7. **持続可能性・修理可能性**: 実物のiMacより修理しやすく(L1〜L3)。分解・整備の手順と工具を最小化。耐久(25,000回)・故障モード・指挟み保護を設計に含める。

## B. 制作思想(作り方)
1. **内部は市販の大手製品、外装だけ特注**。型番・寸法は公式一次資料を優先、非公式は5件以上一致する場合のみ採用。未確認は未確認と書き、推測を確定値にしない(UNVERIFIED台帳 U01〜)。
2. **実物に忠実**: 市販部品は実寸・実形状・端子位置・刻印を再現。モデルと図面と文書は単一源(model/*.json)から生成し、手で数値を二重管理しない。
3. **工学的に成立**: 干渉・曲げ半径・強度・熱・気流・転倒・操作力・公差(ゆるゆる/硬すぎ)を計算とゲート(tools/run_gates.sh)で検査。偽PASS禁止(窓の根拠を示す)。
4. **業界標準の図面**: 第三角法・ISO枠/題名欄・寸法・断面・部品表(外部設計図=ARCTIC/ASUS水準)。STEP/DXF/PDFで業者提出可能に。
5. **履歴を消さない**: 旧版は archive/ に版付きで保存(削除は不可、移転スタブを残す)。復元可能。
6. **再調査の仕組み**: 未確認事項は5時間ごとに再調査(8日間)。
7. **日本語で記述**(サブエージェントへの指示も日本語)。
