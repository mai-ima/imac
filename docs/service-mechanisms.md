# 取り外し・整備機構の設計 (v6)

目的: 各部品を、工具を最小限にして安全に取り外せ、再組立で誤りが起きにくい構造にする。数値は設計値(未承認)で、図面は `drawings/06〜08`(`tools/gen_service_drawings.py` が `model/layout.json` から生成)。標準部品(ネジ・磁石・ガスケット等)の具体的な型番は試作時に確定する。

## 1. 構造の考え方
```
前面モジュール  : 強化ガラス+アルミ枠(接着)  ──M3×16(背面リム)──┐
パネルモジュール: BOE/LG 27型4K               ──M3(取付穴)───────┤  背板(A5052 t2.0)
背板(バックプレート)                                              │   ├─ スタンド(M6×4)
  ├─ キーホール吊りピン×4(肩ネジ、圧入)                          │   └─ ドーム固定(拘束ネジ×2+磁石×12+位置決めピン×2)
  └─ サービストレイ(A5052 t2.0) ←全ての内部部品を搭載
       └─ アンビリカル(eDP/12V/USB)でパネル側と分離
ドーム(背面カバー A5052 t2.0) : 部品を載せない「空の外装」。外すだけで内部に触れられる
```
- **ドームは空**: 部品を載せないので、軽く(約4kg)、位置合わせだけで着脱できる。
- **トレイ方式**: 基板・GPU・電源・AIO・ファン・制御基板をトレイに集約。トレイごと外して机上で作業でき、配線を引き回さない。
- **アンビリカル**: パネル側との境界は、ロック付きコネクタ(eDP 30ピン/12V電源/USB)に限定し、トレイ側とパネル側で完全に分離できる。

## 4. 部品ごとの取り外し機構
### 4.1 ドーム(背面カバー)
- 拘束ネジF1×2を外し、**磁石F3を後方へ引いて**外す。位置決めピンF2とガイド面取りで、再組立時に自動的に位置が出る。
- 縁には**導電ガスケット**(ファブリック・オーバー・フォーム3mm)を周回し、EMIと防塵を確保。ドーム縁と背板のすき間は0.5〜1.0mm。
- ポート/AC入力の開口はトレイ側のブラケットに合わせ、**ドームの開口は±1mmの余裕**+ゴムのグロメット。

### 4.2 サービストレイ(全部品の搭載板)
- トレイは**キーホール吊りピンF4(4点)に掛かる**。重力で落ち着く向きに溝を向け、取り外しは**12mm持ち上げてから背面へ引く**(F5を外した後)。位置(トレイ座標): (60,60), (555,60), (60,210), (555,310)(吊りピンの頭が出るため、部品のない場所を自動探索)。
- 荷重の概算: トレイ全体約7kg(推定) → 4点で1点あたり約17N。M3.5肩ネジのせん断強度に対し十分な余裕(安全率は試作で確認)。
- 取っ手: トレイ上端に折りたたみ式のハンドル(アルミ線)。

### 4.3 アンビリカル(パネル側との分離)
- eDP 30ピン: ロック付きの**同軸ではなく、基板対基板に準じた市販のコネクタ付きケーブル**(長さ約150mm、余長を確保)。パネル側コネクタ MSAK24025P30相当(BOE仕様書記載)に合うケーブルが必要(未確認)。
- バックライト(LED 6ピン)と12V電源、USB(カメラ・マイク)も同一のアンビリカルにまとめ、**取り外し後はコネクタ保護キャップ**を付ける。
- ケーブルには**番号タグと色**を付け、誤接続を防ぐ(コネクタ形状の違いで誤嵌合を防止するのが前提)。

### 4.4 GPU(ASUS Dual RTX 5060 Ti、229×120×50、2.5スロット)
- GPUは**クレードル(工具なしクランプ)**でトレイに保持。カードのブラケット側は市販の2.5スロット用ブラケット穴を使う(位置は製品実物で確認)。
- 外す順: 補助電源(8ピン)を抜く → クレードルのレバーを開く → ライザーを抜く(ラッチを押す) → 持ち上げる。
- ライザーは**カード側とボード側でラッチを持つコネクタ**。曲げ半径が最小になる位置にクリップを設ける。

### 4.5 電源(Corsair SF750、SFX 125×63.5×100)
- SFXの標準取付穴にM3×4で固定(穴位置は規格で決まっているが、座標は設計時に規格書から転記: 未確認)。
- AC入力はトレイ側のブラケットのIEC C14ソケットから**C13ケーブルでPSUへ**(ドームを外してもAC側は動かない)。
- 取り外し: ケーブルを抜く → M3×4 → 引き出す。電源のコンデンサ放電のため、AC抜去後5分待つ。

### 4.6 CPU水冷(ARCTIC LF III Pro 240)
- ラジエーター(277×120×63)は**トレイ上の4点スタンドオフ**でねじ止め(M3、ファン付き一体のまま)。
- ポンプはAM5の標準バックプレートにばね付きネジ×4で固定。**CPU交換時は、先にポンプを外す**(ホース450mmに余長)。
- ホースはクリップで保持し、**曲げ半径(未確認)を守る**固定点を設ける。取り外し時にホースへ力がかからない順序: ポンプ → ラジエーター。

### 4.7 ケースファン(Noctua NF-A12x25)
- **PWMファンハブ**をトレイに固定し、各ファンはハブに挿すだけ。ファンは4点のゴムピン(クイックリリース)で保持し、手でつまんで外せる。

### 4.8 ダストフィルタ
- 吸気は**ドーム下側の傾斜面**(後ろ斜め下向き)に集約。**スライド式フィルタドロワー**(ステンレスメッシュ、磁石で保持)を、背面下側から引き出して洗える。

### 4.9 メモリ・SSD
- メモリ: ドームを外せば上から抜き差し(ポンプとのすき間は未確認。ホース口がDIMM側を向かないよう配置)。
- SSD: ASUS X870-Iのドーターカード方式。ヒートシンク付きSSDの装着可否は実物確認(未確認)。

### 4.10 前面モジュール(ガラス+枠)とパネル
- ガラスはアルミ枠に**構造用シリコーンで接着**し、枠を背板へM3×16(F7)で固定(接着のみの方式より、交換時にガラスを壊さない)。
- F7は**背面リム**にあり、**磁石式トリムリング**で隠す。外すには、薄いへらでリングを起こす。
- パネルは背板にM3(F8)で固定。外すときは**COF部(下端)を押さない**、静電気対策を行う。

### 4.11 スタンドとヒンジ
- スタンドは背面の下リムからM6×4(F9)で外せる。ヒンジは市販の**定トルクヒンジ**(型番は未選定、試験条件: チルト25,000回)。
- ゴム足(4点)は交換可能な貼り付け式。

## 5. 再組立の誤り防止(ポカヨケ)
- ドーム: 位置決めピン2本を非対称配置、磁石の極性をマーク。
- トレイ: キーホールの向きを非対称にし、逆向きには掛からない。
- ケーブル: コネクタ形状と色・番号で識別。ケーブルの最小曲げ半径を示すクリップ位置。
- ネジ: 長さを3種類(M3×6, ×8, ×10)に限定し、組み違いを避ける。
