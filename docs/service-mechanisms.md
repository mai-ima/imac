## 1. 構造
```
前面ガラス(接着) ─ スラブ枠(背板の曲げ縁, 一体)                     ← 前面モジュールを分解する固定ネジは存在しない(P1)
パネル: 背板へM3×約18(後面から) ※ガラスとはエアギャップ0.9(OCA無し)。背板後面に断熱シート3mm(トレイは断熱を挟んでz3〜5)
背板 A5052 t2.0: 吊りピン座×4, ヒンジブロック(M6貫通+裏当て鋼板), 接地スタッドM4, ドーム用ストライク鋼板
サービストレイ A5052 t2.0(z0〜2, 背板に接して吊る) ← 全内部部品(基板は6.35mmスタンドオフ, 他は3mm)
ドーム(空の外装 t2.0): 上辺=掛け爪フック×6, 下辺=1/4回転ラッチ×6(下面の凹み, T10), 位置決めピン×2, 磁石×12(補助), EMIガスケット
```

## 3. 部品ごとの機構
### 3.1 ドーム
下面の凹みから下辺ラッチ6点を1/4回転(T10)→ドームを3mm上へスライドして上辺フックを外し→後方へ。再組立は逆順、位置決めピン2本(非対称)+フックで±0.1mmに戻る。縁のEMIガスケット(圧縮30%程度の低閉合力品, ≤0.175N/mm)。
### 3.2 サービストレイ
拘束ネジ2本→12mm持ち上げてキーホールから外す→**背面へ約100mm引いたところで**アンビリカル(250mm, eDP/12V/USB)と接地編組を外す→取り出す。手でつかむ折りたたみハンドル(上端)。トレイ総質量約6.6kg。
### 3.3 アンビリカル/接地
ロックコネクタ、番号タグ、保護キャップ。接地編組は色タグ付き(復旧チェック)。余長250mm=トレイを100mm引いても届く長さ。
### 3.4 GPU(縦置き)
下端を**クレードル(CP-14)**で支持(自重と衝撃280N)、ライザーのコネクタに曲げ荷重をかけない。外す順: 8ピン→クレードルのクランプ→ライザー→持ち上げ。ホースはGPU下端の下(y<GPU)を通るためGPU交換時に干渉しない。
### 3.5 電源(Corsair SF1000, SFX 1000W)
M3×4+ケーブル(24p/EPS/PCIe/周辺, AC C13)。AC側はC14インレット(下辺中央右)→内部延長C13(約576mm経路)。
### 3.6 CPU水冷
ポンプ(ばね付きM4×4)とラジエーター(M3×4)。ホース出口はポンプの**下向き**(ラジエーターの下端側)。ラジエーターのホース口は下側(気泡はラジエーター上部のタンクに溜まる)。
### 3.7 前面ガラス/パネル
ガラスはスラブ枠へ全周接着(交換は加熱剥離=L3専用、ユーザー整備対象外)。パネルは背板後面からM3を外してトレイ側へ取り出す(トレイを外した後, COF部は押さない)。
### 3.8 スタンド/ヒンジ
ヒンジブロック(背板へ貫通M6×4)。ヒンジ軸は重心の背面側(z=43mm, y=10mm)。バランスばね+摩擦ヒンジ(docs/hinge-design.md)。取り外し時は**ばねを解放してから**(ストッパ位置で固定)ボルトを外す(安全手順)。
## 4. ポカヨケ/復旧
ドームピン非対称、トレイのキーホール向き非対称、ケーブル形状+色+番号、接地編組の色タグ、ネジ長3種(M3×6/8/10)。
## 5. 変更履歴(v6→v7)
肩ねじM3.5×4→M3×Ø5、キーホールにSUSブッシュ、ドーム保持=フック+下面ラッチ+低圧縮ガスケット(磁石は補助)、前面モジュールのM3×16廃止(ガラス直接接着)、トリムリング廃止、ヒンジ軸位置の確定、AC/接地系統の追加、アンビリカル250mm。
