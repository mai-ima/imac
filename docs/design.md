## 2. 設計方針
- 前面: iMac 24"と同比率(本体547 x 374.5mm, 側/上ベゼル10mm, チン68mm, 16:9)。市販23.8〜24型 4K IPSパネル(有効527x296.5)を使用。M6の4.5Kパネルは単体入手不可のため、218ppi→185ppi(4K)で代替。
- 背面下部の**サーマルポッド**(520x190x厚70mm)に市販のMini-ITX + GPU + 電源基板 + 120mmファンを収納。前面スラブは14mm。
- スタンド: 幅130mm 一枚板アルミ(足の奥行147mm)。ポッド重心(約z=42mm)の真下に配置。
- 筐体(お任せ): アルミ板金(A5052)レーザー切断+曲げ+アルマイト(シルバー/ブルー等)、前面は強化ガラス(印刷でチン帯)。CNC削り出しより安価で数量1でも外注可能。ポッドカバーは着脱式(背面ネジ4本)で拡張アクセスを確保。

## 5. 熱・電力 (未検証)
- 想定: CPU ~90W + GPU ~145W + パネル ~30W ≒ 270W。外付け330Wアダプタ想定。
- 下吸気→上排気の自然煙突+120mmファン。GPUはブロワ/ファン入口が前面スラブ側の空間を向く。ファン風量・騒音は実測必須。
- パネル背面とポッドの間は断熱スペーサーを入れる。

## 6. 成果物
- `cad/imac_like_pc.scad` : OpenSCAD 2021.01で構文確認済みの3Dモデル。`cutaway=true` で内部、`color_scheme` で色変更。
- `render/*.png` : OpenSCADレンダリング(front, back, side, internal, lineup_front, lineup_back=公式全7色)。前面は光源の都合で `flip=true` で描画。
- `concept/blueprint.svg` : 寸法入り設計図。`python3 tools/gen_drawing.py` で再生成。
