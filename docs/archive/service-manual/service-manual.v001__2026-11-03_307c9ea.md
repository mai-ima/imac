# 整備マニュアル(案)

注意: 設計段階の手順書です。実機の寸法・部品が確定したら更新します。

## 共通の安全
1. **電源を切り、ACコードを抜き、5分待つ**(電源のコンデンサ放電)。
2. 静電気対策(リストストラップ、導電マット)。
3. 本体重量は推定18kg前後。**2人で扱う**か、机上に寝かせて作業する。ディスプレイ面にはクロスを敷く。
4. パネルの下端(COF部)を押さない。ガラスを持ち上げない。
5. 部品の高温に注意(運転直後は水冷ポンプ、GPU、電源が熱い)。

## 手順A: ドームを外す(L1、約3分)
1. 本体を後ろ倒し(チルト最大)にして、下端リムの拘束ネジ2本をT10で外す。
2. ドームの縁に指をかけ、磁石に逆らって後方へ引く。
3. 取り外したドームは、内側を上にして柔らかい面に置く。

## 手順B: メモリ/SSD/ファン/フィルタ(L1)
- メモリ: DIMMラッチを開いて引き抜く。ポンプのホースに触れない。
- ダストフィルタ: 背面下側のドロワーを引き出し、水洗い→乾燥。
- ファン: ゴムピンを外し、ハブからコネクタを抜く。新しいファンは回転方向(矢印)を確認。

## 手順C: トレイを取り出す(L2、約10分)
1. 手順Aを実施。
2. アンビリカル(eDP、LED、12V、USB)をタグ番号どおりに外し、キャップを付ける。
3. トレイ下端の拘束ネジ2本を外す。
4. トレイを**12mm持ち上げて**キーホールを外し、**背面へ**引く(両手、約7kg)。
5. 机上のトレイに「静電気マット」を敷いて作業する。

## 手順D: GPUの交換(L2)
1. 手順C。
2. 8ピン電源を抜く。ライザーのラッチを押して外す。
3. クレードルのレバーを開き、GPUを持ち上げる。
4. 新しいGPUを同じ向きで置き、レバーを閉じ、ライザーと電源を差す。
5. 組み立ては逆順。**取付後、BIOSでGPUが認識されるか確認**。

## 手順E: 電源の交換(L2)
1. 手順C。AC側C13ケーブルを抜く。
2. 電源のM3×4を外し、ケーブル(24ピン/EPS/PCIe/SATA)を抜く。
3. 新しい電源は、**ケーブル長(300〜400mm)で届くか**を確認(未確認の項目あり)。

## 手順F: CPU・水冷(L2)
1. 手順C。
2. ポンプのばね付きネジ×4を対角に少しずつ緩め、外す。ホースに余長があることを確認。
3. ラジエーターのM3×4を外し、ポンプと一体で取り外す。
4. CPU交換時はソケットレバーを操作(AM5)。**サーマルペーストの塗り直し**(ARCTIC MX-6 0.8g付属)。

## 手順G: パネル/前面ガラス(L3)
1. 手順Cでトレイを取り出す。
2. 背面リムのトリムリングを起こして外し、M3×16(F7)を外す。
3. 前面モジュールを背板から外す(吸盤を使用)。
4. パネルのM3を外す。COF部を押さない。

## 手順H: スタンドを外す(L3)
1. 本体を寝かせ、背面の下リムのM6×4を外す。ヒンジを回さずに外す。

## 記録
各作業の実施日・実施者・結果を整備記録に残す(`docs/service-log.md` に追記予定)。
