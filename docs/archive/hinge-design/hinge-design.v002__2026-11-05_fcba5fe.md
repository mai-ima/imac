# ヒンジ(チルト機構)設計 v1 (2026-11-05)

## 要求
- 質量: ディスプレイ部13〜19kg(実測で確定)。チルト -5°〜+25°(要: 実機の見やすさ試験)。どの角度でも停止、片手で操作(上端で ≤20N)。25,000回の耐久。落下事故の防止(単一故障で落ちない)。
## v7 追記(監査C-7/C-8対応)
- **ヒンジ軸を spec.json hinge に確定**: z=43mm(前面ガラスから, 重心の背面側), y=10mm。-5°〜+25°で必要トルクがほぼ一方向(後方へ倒れる向き, 約0〜10N·m)になり、符号反転(オーバーセンタ)を避けられる。
- ばねは**角度に応じて増えるトルク曲線**(τ≈m·g·dy·sin a)に合わせる: 定荷重ばね単体では一定トルクなので、**カム/リンクで有効アームを変える方式**(U26)または、ばねトルクを平均値に合わせ残差±約1.5N·mを摩擦ヒンジで保持。
- ヒンジブロックは背板へ**貫通M6×4+裏当て鋼板+補強板**(2mm板へのタップ禁止)。
- 質量は layout 由来の massmodel(13.7kg)。実測(U25)で再計算。

## 結論: カウンターバランス+対称摩擦ヒンジの併用(摩擦のみは不可)
1. **重力モーメントの相殺**: 定荷重ばね(constant-force spring)またはガススプリングを背板下部とスタンド腕の間に配置し、トルク曲線 τ(a)=m·g·(dz·cos a+dy·sin a) の概形(§docs/joint-analysis.md)を相殺。ばね部品の型番は未選定(U26)。
2. **残差保持**: Reell PHL/PHC級の対称トルクヒンジ(2〜4個, 各 0.9〜3.4N·m, 50,000回)を同軸で並列。
3. **冗長性(フェイルセーフ)**: ばね保持部品は**金属製**(iMacの樹脂キャップ劣化事例)。ばね破断時にも本体が急降下しないストッパ(最大傾斜を機械的に制限)と、ヒンジ摩擦だけで保持できる最小トルク(落下速度を抑える)を確保。
4. **取付**: スタンド腕はドーム下の背板リムにM6×4で固定(docs/service-mechanisms.md)。ヒンジ軸は背板の下リム、ドーム切り欠きの内側。軸位置zは重心を考慮して最適化(軸をCGに近づけるほど必要トルクが減る)。
