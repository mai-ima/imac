# 製作ガイド(自作部品の作り方・調達・組立・試験)

図面一式: `drawings/` — 01〜05=外装製造(MFG)、06〜08=整備(SVC)、09〜15=基板配置/配置図/断面/配線/エアフロー/分解組立/BOM(PKG)。生成: `tools/gen_*.py`(元データ `model/*.json`)。

## 1. 自作する部品(外装)と製法
| 部品 | 材質/厚み | 加工 | 表面処理 | 図面 | 外注先の目安 |
|---|---|---|---|---|---|
| 前面ガラス+アルミ枠 | 化学強化ガラス+A6063枠 | ガラスCNC外形、枠は押出+CNC | AR/防汚、枠はアルマイト | 01 | ガラス加工業者、板金メーカー |
| 背板(バックプレート) | A5052 t2.0 | レーザー+曲げ+CNC(キーホール/ネジ穴) | アルマイトII | 02 | 板金試作(例: ミスミ/MISUMI系メーカー、板金屋) |
| サービストレイ | A5052 t2.0 | レーザー+曲げ(角R18)、スタンドオフ圧入 | 導電アルマイト(接地)または化成処理 | 06 | 板金試作 |
| ドーム | A5052 t2.0 | 絞り/プレス or 5軸CNC+板金溶接(試作は樹脂3Dプリント型で絞り) | アルマイトII+EMIガスケット溝 | 03, 07 | 板金絞り業者 |
| スタンド+ヒンジ | A6063 押出+定トルクヒンジ | CNC | 硬質アルマイト | 05 | 切削加工業者+市販ヒンジ |

## 2. 購入リスト(市販品)
`docs/bom-final.md` / `drawings/15_bom_sheet.svg`。購入前の必須確認: U01(BIOS)、U06/U09(GPU+ライザーのPCIe互換)、U13(パネル制御基板の保証付きキット)、U12(メモリ型番)。

## 3. 組立順(`drawings/14_exploded_assembly.svg` と同じ)
1. 背板: 吊りピン×4(M3.5肩ネジ・トルク0.8N·m)、スタンドM6×4(6N·m)。
2. トレイ(机上): スタンドオフ→基板→CPU(グリス)→ポンプ→DIMM→SSD→ラジエーター→PSU→GPU(クレードル)→ライザー→ファン→ctrl基板。
3. 配線(`docs/wiring.md`): W1(24p)→W2(EPS)→W3(PCIe)→W4(12V)→ファン/ポンプ(基板ヘッダ)→W5(アンビリカル)。タグ・コームで固定。
4. 机上で通電試験(パネル無し): BIOS起動、メモリEXPO、ファン回転、ポンプ回転、温度。
5. 前面モジュールを背板へ、トレイを吊りピンに掛けて拘束ネジ。アンビリカル接続。
6. ドーム(磁石+拘束ネジ×2)、トリムリング。

## 4. 受入試験(未実施・合格基準案)
- 負荷: CPU(Cinebench/Prime95 30分)+GPU(FurMark 30分)同時で、CPU<90℃(Tjmax95)、GPU<83℃、VRM/SSDは各メーカー上限-10℃以内。
- 騒音 目標≤38dBA(1m, 負荷時)、表面温度 手が触れる外装≤48℃(IEC 62368-1 の金属接触の目安: 要確認)。
- 長時間: アイドル48h+負荷8hのエラー無し。チルト25,000回(ヒンジ)。振動/輸送: 梱包落下試験。
- 安全: AC→筐体の保護接地導通≤0.1Ω、絶縁抵抗測定(要資格者)。

## 5. 既知の設計課題(2026-11-05 更新)
- 解消: ctrl_boardのドーム超過(左下へ縦置きに移動)、SSDとポンプ干渉(SSDをM.2ドーターカード位置・z14へ)。fitcheck/layout_search/図面/Blenderのドーム内面関数はsmoothstepに統一。
- 残: DIMM2枚の厚み(約12mm)とlayout箱(8mm)、ポンプ外形とDIMMの間隔(実物)、基板VRM/ドーターカード高さ(U02)、ライザー曲げ半径(U09)、ホース曲げ半径、IO並び(U03)、取付穴座標(U17)。
