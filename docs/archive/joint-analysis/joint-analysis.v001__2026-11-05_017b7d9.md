## 2. ヒンジ保持トルク(チルト角 a で本体を保持するのに必要)
式: τ(a) = m·g·(dz·cos a + dy·sin a)。m=13.3kg, 重心オフセット dz=-37mm(軸より背面側が+), 軸から重心の高さ dy=216mm。

| チルト a | 必要トルク N·m | 備考 |
|---|---|---|
| -5° | -7.3 | 前方へ倒れる向き |
| +0° | -4.9 | 前方へ倒れる向き |
| +10° | 0.1 | 後方(上向き)へ倒れる向き |
| +20° | 5.1 | 後方(上向き)へ倒れる向き |
| +25° | 7.5 | 後方(上向き)へ倒れる向き |

**問題**: 最大 7.5 N·m を摩擦だけで保持する定トルクヒンジは、ユーザーが指で傾ける力(上端で約18 N)になり**実用的でない**(市販の定トルク/フリクションヒンジは数N·m級が主流: 要調査, docs/research-hinge.md)。

### 対策案(要設計判断)
- **A. カウンターバランス**: 定荷重ばね/ガススプリングで重力モーメントを相殺し、残りを小トルクの摩擦で保持(Apple Studio Display / iMac式)。相殺トルクの目標: ±1.1N·m 程度の残差。
- **B. 回転軸を重心の高さに近づける**: dyを減らす(軸を本体中央付近へ)。ただし軸のアームがトレイ/ドームを貫通せず背板に取り付く構造が必要(スタンド腕を背板直付け→ドーム下端の切り欠き)。dy を 216→100mm にすると最大トルクは約 1.1 N·m。
- **C. チルトを固定段階(ラチェット)にする**: 段数を減らす代わりに摩擦を不要にする。

## 4. ドーム固定(磁石・ガスケット)
- ドーム外周長 ≈ 1947 mm。
- **磁石の相手は鉄系が必要**: アルミは非磁性のため、背板側に鋼板(SPCC/SUS430)のストライクプレートが要る。磁石単体の吸着は鋼板接触で約2〜2.5kgf(N52 φ8×3, メーカー値要確認)、ガスケット圧縮後の実隙間1mmで低下(定性的に1/3程度)。
- 12個の磁石の合計保持力(隙間1mm想定): 約 84 N(1個7Nと仮定: 未検証)。
- EMIガスケット閉合力 0.05 N/mm × 1947mm = 97 N。
- EMIガスケット閉合力 0.175 N/mm × 1947mm = 341 N。
- EMIガスケット閉合力 0.5 N/mm × 1947mm = 973 N。
- **結論**: Parker SOFT-SHIELD 3500の公称閉合力は<1lb/inch(≈0.175N/mm, docs/research-joints.md)→ 最大 341N に対し磁石12個は約84N(未検証)で不足。**ガスケットを低圧縮で使う(圧縮率を30%程度に抑える)うえで、4分の1回転ラッチ(または拘束ねじ)を上側にも増設して計6点以上にする**。実測で調整(U21)。

## 7. その他の接合部リスク(要試験)
- アルマイト層は絶縁(Type II 約10〜25µm)。接地導通が必要な箇所(ドーム縁, トレイ-スタンドオフ, 背板)はマスキングまたは導電(アロジン/化成)処理。
- ステンレス締結具×アルミ: 乾燥環境では実用上問題が小さいが、結露時のガルバニック腐食に対しアルマイト+グリース/シーラント。
- ホース(EPDM系,ARCTIC): 透過による冷却液減少(数年)と、ポンプ上方の気泡溜まり(ディスプレイ縦置き)。ラジエーターを高所、ポンプを低所に置く(本設計: ラジエーター上端がポンプより高い → 気泡はラジエーター上部のタンクに集まる)。
- GPU縦置き: 長軸が鉛直。重量を支えるのは下端ブラケット/クレードル。ライザーのPCIeコネクタ(横向き)に曲げモーメントを与えないこと。
- ファン軸受(スリーブ/FDB)の姿勢依存: ファン軸が水平(ディスプレイ縦置き)でも寿命が低下しにくい軸受(FDB/SSO)を使う。Noctua NF-A12x25はSSO2、ARCTIC P12 ProはFDB(仕様は要確認)。
