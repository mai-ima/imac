## 懸念と対策
- 縦置きディスプレイ背面は自然対流が上向きに働くため、吸気を下側/排気を上側に偏らせると効率が上がる(v7: 均一格子+内部の仕切りで流路を作る案をCFDで評価)。
- GPUファンはドーム側の空気を吸う → 内部温度が上がるとGPU温度が直接上がる。内部温度上昇を≤10K(B)に抑える風量を確保。
- PSU/ポンプVRMファン/基板は局所温度を別途実測。パネル背面温度≤45℃を要確認(バックライト寿命)。

## 試験計画(未実施)

2. 負荷: Cinebench 30分+FurMark 30分同時。室温25±2℃。ファンRPMとSPLを同時記録。
3. 合格: CPU<90℃, GPU<83℃, 内部上昇≤10K, パネル背面≤45℃, 外装表面≤48℃, 騒音≤38dBA。
4. 不合格時: 格子の開口率拡大、ラジエーターを直排気にする仕切り、ケースファン増設(2基)。
