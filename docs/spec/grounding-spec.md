# 保護接地(PE)・EMC・静電気 仕様 v7

目的: クラスI機器として、AC入力のPEから**接触可能な全金属部**への低抵抗導通を保証する(監査指摘 C-6)。陽極酸化皮膜は絶縁のため、接地は**専用の導体**で取り、嵌合面の接触に頼らない。

## 1. 構成
```
AC C14 インレット(PE端子)
  └ AWG16 緑/黄, M4リング端子 ≤200mm ─→ [トレイ接地スタッド M4] (トレイ導電化成面)
        ├ ボンディング編組 6mm² ×2 ─→ [背板接地スタッド M4](皮膜マスク)
        │     ├ 編組 ─→ ヒンジブロック/スタンド(接触可能な金属)
        │     └ 編組 ×2 ─→ ドーム(接地ラグ M3, 皮膜マスク)  ※ドーム縁の導電ガスケットは副経路
        └ PSU: C13ケーブルのPE + 筐体(スタンドオフ経由)で二重化
```
## 2. 規則
- 接地用ねじ・ラグ周囲は陽極酸化を**マスキング**(径8mm)、またはMIL-DTL-5541 Class 3相当の導電化成処理。歯付座金を併用。
- 各接触可能金属部〜PE端子間の抵抗 ≤ 0.1Ω(測定: 有資格者, 10A級試験)。
- トレイ・ドーム・ヒンジは**着脱するため**、編組は脱着可能なリング端子+M4/M3ねじ。整備手順に「接地編組の取り外し/復旧」を含める(復旧忘れ防止: 色タグ+手順書のチェック)。
- ガルバニック: 裸アルミ(マスク部)×SUSは結露時に腐食し得るため、接地部に導電グリース/コンパウンド(例: 酸化防止導電コンパウンド)を塗布。
- 静電気(ESD): 外装が金属で接地されるため放電経路は成立。ガラス面の帯電は防汚コート表面抵抗で管理(U)。
- EMC: ドーム縁の導電ガスケット(CP-08)+格子(Ø2.4, 6GHzで約15dB程度と概算 U31)。VCCI/電波法適合は未評価(販売する場合は外注評価)。
## 3. 未解決
