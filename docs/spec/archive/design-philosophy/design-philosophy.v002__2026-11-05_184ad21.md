# デザイン思想と設計規則 (Appleのデザイン哲学をオマージュ) v7

注記: 本書は、Appleが公に語ってきたデザインの考え方(「より少なく、しかしより良く」の系譜、ユニボディ、隠された締結、均一なすき間、素材への誠実さ、静かな性能など)を、本プロジェクトの設計規則に翻訳した**自己解釈**であり、Appleの公式文書ではない。Appleのロゴ・商標・固有意匠は使用しない(オマージュに留める)。

## 1. 原則と設計規則
| # | 原則 | 設計規則(検査可能な形) |
|---|---|---|
| P1 | 単純さ: 目に見える要素を最小に | 外面に見える締結具・分割線・ロゴ・ラベルは**ゼロ**(背面ポート開口と通気面を除く)。外装部品の面数/色は最小。 |
| P2 | 一つの塊に見える(ユニボディ感) | 前面は**一枚のガラス面**、背面は**一つの連続した曲面シェル**。接合線はスラブ側面1本(0.5mm均一)のみ。 |
| P3 | 均一なすき間・面一(ツライチ) | 外装の継ぎ目すき間 0.5±0.1mm、段差≤0.1mm。ガラス-枠-ドームの面一。 |
| P4 | 隠された機構 | 固定はすべて**視線から隠れた位置**(下面・内側・トリム裏)。操作は下面/内側から。 |
| P5 | 素材に誠実・本物 | アルミ+ガラスのみ(樹脂は非露出またはRF窓のみ)。塗装で金属を偽装しない。アルマイトの色は材料色。 |
| P6 | 連続曲率・一貫した半径 | 外形の角Rを統一(ドームR50は本体R10とG2連続を目指し、断面は smoothstep 曲線)。エッジは0.2〜0.5mmの均一面取り。 |
| P7 | 静かな高性能 | 騒音≤38dBA。ファン/ポンプは視覚的にも聴覚的にも主張しない。通気は**面全体の均一なパーフォレーション**(局所の穴パターンを作らない)。 |
| P8 | 機能を装飾にしない | 通気は機能のための均一格子、ロゴ/装飾の追加なし。外観のためだけの部品を置かない。 |
| P9 | 細部への執着(見えない所まで) | 内部も配線を整然と(固定点・曲げ半径)、部品間のクリアランス均一、内部の見える部分(ドームを外した時)も美しく。 |
| P10 | 使う人への敬意(体験) | チルトは片手で滑らかに、どこでも止まる。電源ボタン/ポートは手探りで分かる位置。 |
| P11 | 持続可能性・修理可能性 | Apple一体型より**修理しやすく**(L1〜L3整備)。単一素材(アルミ)でリサイクル容易、接着は前面ガラスのみ。 |

## 2. 現設計の適合監査(v6→v7)
| 規則 | 現状(v6) | 判定 | v7の対応 |
|---|---|---|---|
| P1 外面に見える締結具なし | ドーム下縁に拘束ネジ/ラッチが露出、トリムリング | 不適合 | ラッチ操作は**下面(床側)の凹み**に隠す。上辺は**フック掛け**(ネジ無し)。前面M3はトリムリングで隠蔽(維持) |
| P2 連続した背面 | ドームは連続だが、局所の六角穴3領域・I/O開口・RF窓が点在 | 不適合 | 通気は**全面均一パーフォレーション**1枚(プラトー全面)。RF窓はパーフォレーション領域の内側(透過)に統合 |
| P3 均一なすき間 | ガスケット溝/位置決めピンのみで規定なし | 未規定 | すき間0.5±0.1を図面で規定、ドームは位置決めピン+フックで±0.1 |
| P4 隠された機構 | ばね/ヒンジはスタンド内、ラッチ1/4回転が背面側面に | 一部不適合 | ラッチは下面へ。ヒンジはスタンド腕内の隠し機構 |
| P5 素材に誠実 | アルミ+ガラス+黒塗りチン(塗装)。RF窓は金属調塗装 | 要確認 | チン面は**ガラス裏面の印刷(従来のiMac手法)**として許容。RF窓は樹脂の素地色でなく、通気格子と同じ見えに(格子の裏に樹脂板) |
| P6 連続曲率 | ドームはsmoothstep内面、外形は角R50 | 概ね適合 | 外面もsmoothstepで連続、縁の面取り均一化 |
| P7 静かな高性能 | 3領域の局所穴+フィルタドロワー | 不適合 | 全面均一格子+全面フィルタ(磁石式メッシュシート)。ファン曲線とSPLの実測 |
| P8 装飾を置かない | 背面ロゴ無し(適合) | 適合 | 維持。ロゴ無し |
| P9 細部 | 内部配線は固定点あり、ドーム内側は黒つや消し | 適合(要実機) | ドーム内側もアルマイト色同系で整える。配線タグ |
| P10 体験 | ヒンジは未選定部品 | 未達 | docs/hinge-design.md(カウンターバランス) |
| P11 修理可能性 | L1〜L3整備 | 適合 | 維持 |

## 2b. 工業デザイン監査(ラウンド3, 2026-11-05)の結果と対応
総合C+(前面と色はA-、背面/側面/図面整合がC)。対応(v7.1): ①ドーム縁の垂直壁15mm廃止→縁内奥行6mm・傾斜70mm(側面の縁を薄く), ②穿孔を実穴からテクスチャ表現へ(モデル軽量化)+内側に黒メッシュフィルタ(内部を隠す), ③ポート開口を細い3スロットへ縮小(統合は残課題), ④スタンド足を260×245→220×215(+鋼板ballast 2kg, stability.py OK), ⑤ヒンジ軸の鋼円柱を同色アルマイトに, ⑥ガラス/表示/カメラを面一, ⑦チンは「塗装」でなくガラス裏面印刷に統一(図面01の白縁/黒ベゼル矛盾を解消), ⑧図面03をt2.0/Ø2.4×4.0へ再生成。**未対応(残課題)**: 厚み116mmの根本的な薄型化(冷却要件との両立は不可能に近い), 開口の1本スロット化(GPUブラケット位置の再設計が必要), 本体/スタンド合金統一とアルマイトロット管理, カメラ/マイク/スピーカー(U14), 縁の完全なG2連続(最大傾斜約65°→40°以内へ: run拡大が必要)。

## 3. v7 の主な設計変更(原則に基づく)
1. **背面を均一なパーフォレーション1枚に**: 局所の六角穴3領域を廃止し、ドーム平坦部〜肩部を覆う均一格子(Ø2.4×ピッチ4.0の千鳥, 開口率≈33%)に。有効開口面積は約54,000mm²相当を確保(風速約1m/s@200m³/h)。内側に**全面のメッシュフィルタ(磁石で保持, 1枚)**。
2. **締結を隠す**: ドームは上辺の**フック(6点)**に掛けて下げ、下辺の**下面ラッチ(6点, 下向きの凹みからT10)**で固定。背面/側面に締結具・ラッチは見えない。トリムリング(磁石)は維持。
3. **RF窓**: 通気格子の領域内(上辺)に、金属格子の裏側に樹脂板(PC t2.0)を置く。外観は格子のまま、電波は格子を通る(Ø2.4穴は6GHzの波長50mmに対し透過損失の要検証: U31)。
4. **I/O**: 背面左下の傾斜面に**凹みチャンネル(幅12×長さ120)**を設け、ポートを面から引き込む。ボタン/LED無しで電源ボタンのみ(触覚)。
5. **すき間規定**: ドーム-スラブ 0.5±0.1、ガラス-枠 0.5±0.1、段差≤0.1。
6. **色の扱い**: 背面・スタンドは同一素材色(アルマイト)、チン/ベゼルは淡色(背面印刷)。ロゴ・刻印は外面に無し。
