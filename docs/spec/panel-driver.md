# パネル駆動(コントローラ基板)仕様と採用ゲート — 監査C-10対応

**この項目は設計全体の最大リスクであり、型番確定まで「購入前条件(ゲート)」とする。**

## 1. 要求(BOE MV270QUM-N50 公式データシート由来 / LM270WR3-SSC1は一部のみ確認)
- インターフェース: eDP 4レーン, 30ピン(Panelook PDF)。パネルVDD 10V、バックライトは別系統(PBL≈23.5W, Ptotal≈32.5W typ / 37.3W max)。60Hz。
- 入力: DisplayPort/HDMI(GPU出力→コントローラ→eDP)。USB(カメラ/マイク)はPC内部のUSBヘッダ。
- 電源: 12V入力(PSUのSATA/周辺ケーブル, U34)。コントローラが10V VDD/バックライト駆動を生成。
## 2. 採用ゲート
| 候補 | 状態 | 判定 |
|---|---|---|
| Data-Modul 等 産業用ディスプレイ+制御基板(保証付きキット) | サイト取得不可(503/403) | 第一候補: 問合せ必須(U13/U37) |
| 汎用ドライバ基板キット(Amazon B0F5VVQQCD 等) | 適合未確認、ノーブランド | **大手/信頼性の原則に反するため例外扱い**(理由と代替を明記して選定) |
| 市販の27型4K eDPモニタをそのまま使う(パネル+基板ごと) | 未検討 | 代替案: 保証付きだが外形/厚み/コネクタが合うか要調査 |
**ゲート**: 型番・外形・コネクタ位置・保証の確認が取れるまで、ctrl_board(55×150×15, assumed)の寸法は仮置きで、トレイに「予約空間」として確保する。
## 3. 機構要件(v7)
- 背板に**アンビリカル貫通開口 30×10**(トレイ上端左寄りでなく、ctrl_board近傍)。ハーネス全長380mm(経路約274mm+整備余長100mm, W5=cables.json)、eDPは最小曲げ半径(要データシート)、ロック付き。
- パネル背面コネクタの位置(BOE Fig.)と背板開口の整合、パネル背面〜背板のギャップ1.0mm内にコネクタが収まること(要確認)。
- 12V供給: W4(SATA/周辺, 経路24mm=cables.json)。
## 4. 試験
点灯、60Hz同期、バックライト調光(PWM)、コールドブート、温度(コントローラ≤70℃)、EMC。
