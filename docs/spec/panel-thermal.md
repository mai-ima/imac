## 熱で画面が壊れる/劣化する主なリスク(深刻度: 設計者判断)
1. パネル表面温度がLCM上限48℃超 → 長期信頼性低下(高)。2. 液晶の等方相転移(透明点)に局所的に近づき**黒いシミ/ムラ**(高; iMacの黒シミ報告は熱原因の主張が複数あるが公式見解なし)。3. バックライトLEDのジャンクション温度上昇で輝度低下・寿命短縮(高、寿命は温度に指数的)。4. 偏光板の収縮/剥離、導光板・光学シートのウェーブ(中〜高、ヨウ素系偏光板は約90℃付近で劣化との特許記述)。5. 背板の不均一温度によるパネルの熱膨張差/ムラ(中)。6. 結露(停止時の冷え込み、水冷低温部)(中)。7. COF/ドライバICの温度(中)。8. ガラス熱応力・シール剤劣化(中)。9. 背板たわみによるパネルへの接触(中)。
## 現設計(v7.1)の問題
背板-パネル間隙1.0mm(伝導のみ)は熱抵抗≈0.19K/W(A≈0.2m²)で、背板がパネルより30K高いと約150W相当が伝わる計算 → **不適切**。
## 設計変更(v7.2)
| 項目 | v7.1 | v7.2 |
|---|---|---|
| パネル背面〜背板の空気層 | 1.0mm | **4.0mm** |
| 断熱層(背板の前面側内面) | なし | **3.0mm 断熱シート(エアロゲル/フェノールフォーム等 k≤0.04W/mK)** |
| トレイ〜背板 | 直接接触(z0〜2) | **3.0mm 断熱スペーサ**(PEEK/ガラエポのブッシュ+断熱シート)を介し、熱的に分離(トレイz3〜5) |
| スラブ厚 | 19mm | **25mm**(1.1+0.9+13.3+4.0+3.0+2.0=24.3, 余裕0.7) |
| ドーム総厚 | 116mm | **125mm**(内奥行94mm維持, トレイ+3mm分) |
| 温度監視 | なし | **背板パネル側に温度センサ**(制御基板): 45℃でファン連動、48℃でバックライト減光 |
| 拡散 | なし | 背板をアルミのまま(拡散)、断熱とセットで使用 |
## 熱抵抗の見積り(面積当たり m²K/W)
空気4mm=0.154、断熱3mm(k=0.035)=0.086、合計≈0.24 → 全体(A=0.2m²)で約1.2K/W。1mm空気(0.038, 0.19K/W)に対し約6倍。背板が25K高温でも伝熱は約20W。
## 目標値(自己設定の運用値。実測で確認するまで量産前提にしない)
背板パネル側面: 目標≤40℃(室温25℃)、警告45℃、強制対処48℃。35℃環境でも48℃以下(超過時は制御で復帰)。
## 試験計画
K型熱電対: パネル背面(中央/上/下/GPU直上)、背板両面、LED基板近傍/COF近傍(可能な範囲)、ドーム内空気、水冷水温、電源表面。GPU+CPU最大負荷、室温25/35℃、輝度100/50%、定常まで測定後の停止で結露確認。合格: パネル背面最高≤40℃(25℃)、表示ムラ・黒シミなし。
