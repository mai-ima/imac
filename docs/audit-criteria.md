# 監査基準 (厳格版)

ループは、全カテゴリが **合格(A)** になるまで終了しない。判定は監査用サブエージェントが、公式資料(寸法図・マニュアル・仕様書)と画像を突き合わせて行う。根拠が取れない項目は「未確認」とし、未確認が残る限りA判定にしない。

## 判定段階
- **A 合格**: 公式資料で裏付けが取れ、モデル/設計に正しく反映されている
- **B 要修正**: 反映ミス、または軽微な差(寸法±0.5mm超〜±2mm、色の誤り、部品数の違い)
- **C 不合格**: 不適合・干渉・誤った構造・存在しない機能の表示、寸法±2mm超
- **U 未確認**: 公式の裏付けが得られていない(→ 設計側は安全側の余裕を取るか、実物確認を購入前条件にする)

## カテゴリと基準
### 1. 部品選定(信頼性・相性)
- 大手メーカー品(主要ブランドの量産・保証付き)であること。ノーブランド/出品者依存品は「例外」として理由と代替を明記
- 最新規格: CPUソケット世代、DDR5 / PCIe 5.0、USB4/Thunderbolt相当、Wi-Fi 7、2.5GbE以上を満たすか
- 相性: ソケット対応、BIOS/AGESAバージョン(CPU対応)、メモリQVL/EXPO、電源コネクタ種別(12V-2x6/8ピン)・容量、PCIe帯域、ライザーのPCIe世代、冷却ソケット金具
- 性能: iMac(M6, 12コア)を上回るCPU/GPU性能を、公開ベンチ値で説明できること
- 拡張性: 空きスロット(DIMM/M.2/PCIe)、ヘッダ、増設余地を明記

### 2. 寸法・配置(機械設計)
- 全部品の外形が公式寸法と一致(±0.5mm)。軸の意味(長さ/高さ/厚さ)が明記されている
- 取付穴・コネクタ位置を公式図面で確認し、固定方法が成立している
- 干渉チェック(AABBではなく実形状に近い判定)・曲げ半径・ケーブル最小曲げ(ライザー/フレキ/電源線)
- 筐体の公差積み上げ(幅・厚さ)が成立

### 3. 電気・熱
- 電源: ピーク負荷(CPU PPT + GPU TGP + その他 + パネル)に対する余裕≥30%、各レール・コネクタ数
- 熱: 主要部品ごとに冷却能力(クーラー定格・ファン風量/静圧・通風経路)が足りること。単純な熱収支だけで合格にしない(必要なら概算のCFD/実験計画を添える)
- 配線: 電源線・信号線の長さが実測の経路に届く(ケーブル仕様の公式長さ)

### 4. 外観の再現度(写実性)
- 各製品のロゴ・刻印・ラベル・シルク文字・基板色・コネクタ形状・ネジ位置・部品数(コンデンサ、チョーク、MOSFET等)が実物写真/公式画像と一致
- 実物写真で位置が確認できないものは再現せず「未確認」と明記(推測で作り込まない)
- 材質(アルマイト、ガラス、PCB、プラスチック)の見え方、エッジの面取り
- 配線の経路が現実的(重力・曲げ半径・固定点)

### 5. ドキュメント
- 自作部分(外装・スタンド・ポッド)の製造図面(寸法・公差・材質・表面処理)
- 組立手順、配線図、検査/試験計画、購入リスト(型番・リンク)

## ループの終了条件
- 全カテゴリが A、または「未確認」が購入前確認項目として文書化され、かつ設計が安全側に倒れている
