## 3. 実物クオリティに達するための優先順位つき作業計画
1. **P0(根拠・基準の是正)**
   - (a) IHS 高さを AMD 規定 7.98±0.6 に(MDA-017)。連動して cooler/pump の z、ホース長、`tools/cable_check.py` を再検査。AMD 公式機械図面を取得して[UV]解除。
   - (b) I/O ポートを「開口+奥行+舌片+接点」で再実装(MDA-009〜015)。USB-A 12.5×5.12×8.88、Type-C 8.34×2.56×6.2 の確認済み寸法を使う。
   - (c) VRM ヒートシンクの分割・フィン・ファン・L字延長(MDA-001, 006, 008)。高さは公式資料に無いので**[UV]のまま**、写真で複数(5件以上)突合してから確定。
2. **P1(物理矛盾の解消)**: MDA-002/003/004/005/007/019(干渉・めり込み)、MDA-025/026(PCIe スロット・ライザー嵌合)、MDA-022/033(DIMM 挿入・M.2 カード支持)、MDA-016(ソケット)。配置図 p.14 の x/y 向きの取り違えの有無を最初に再確認(EPS とねじ穴、チョークとソケットの矛盾は読み取り誤りの強い兆候)。
3. **P2(形状の作り込み)**: MDA-009 以降のコネクタ類(ATX24/EPS/ヘッダ/Type-C ヘッダ)、チップセット/M.2 スタック、DIMM のスプレッダ、PCB の穴・シルク・テクスチャ(乱数配線の廃止)、SMD の整列化。
4. **P3**: LED・電池・ねじ形状・ASM 接頭辞整理。
5. **検査の新設**(CLAUDE.md INTF-01): 基板部品の AABB 重なり・浮きを検出するテストを `tools/` に追加(包絡箱でなく、実メッシュまたは開口/挿入量を含む)。偽PASS防止のため、挿入量が 0 の嵌合は FAIL とする。
6. **台帳登録(親が実施)**: MDA-001〜040 を audit_control/tasks.json へ。[UV]項目(ソケット実寸、IHS 外形、ヒートシンク高さ、DIMM の JEDEC 図面、ポート色、ATX24 色、SMA/Q-Antenna 種別、右縁ヘッダ対応、ドーターカード構成)は UNV-01 の調査対象。
