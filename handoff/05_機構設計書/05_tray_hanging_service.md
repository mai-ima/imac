# 05 サービストレイの吊り(キーホール)と引き出し
> 状態: 設計値(PRELIMINARY・未試作)。数値は model/spec.json・model/balance.json と tools/ の計算から自動埋め込み。未確認事項は末尾の表(U台帳 docs/unverified-tracker.md)。

## 1. 目的
全内部部品を載せた**サービストレイ**(A5052 t2.0, 約6.6kg)を、背板へ4点のキーホールで吊り、背面側へ引き出して整備できること。
## 2. 構成(CP-04/CP-05/CP-06)
| 要素 | 仕様 |
|---|---|
| 吊りピン | SUS304肩ねじ M4、肩Ø6 h8×6.0(支圧部=トレイ+ブッシュ3.0)、頭Ø10×t3(CP-04)。背板PEM TSOA(M4)へ1.7N·m+ネジロック |
| キーホール | 丸Ø10.2+溝W6.5×長さ(トレイを12mm下げて掛ける)。縁はSUS304 t1.0ブッシュ(CP-05)で補強 |
| 位置 | `model/layout.json` の keyholes(4点) |
| 拘束 | M3 T10 拘束ネジ×2(下辺)。吊りが外れないようロック |
| トレイ外形 | 570×351.3(角R38)、外周10mmはドーム固定ハード用に空ける |
## 3. 荷重(輸送衝撃30G)
トレイ質量約6.6kg×30G=1,942N。**上側2点のみが荷重を受ける最悪ケースで1点約978N**(4点均等なら485N)。肩Ø6のせん断≈35MPa(SUS304)、支圧は実効t3.0のブッシュで約54MPa、**肩根元の曲げは腕2.5mmで約114MPa(許容137MPa, strength_check)**。雌ねじ引抜き耐力 U29(未検証)。キーホール溝W6.5と吊りピン肩Ø6のすき間は公称0.5mm、4点の位置公差(keyhole_pos_stack 0.2)を含めてもがたつき上限0.6mm以内かを tools/fit_tolerance.py で検査。
## 4. 引き出し手順
拘束ネジ2本 → 12mm持ち上げてキーホールから外す → 背面へ約100mm引く → アンビリカル(全長380mm、整備余長100mm込み)とPE編組を外す → 取り出す。
## 5. 故障モード
| 故障 | 影響 | 対策 |
|---|---|---|
| キーホール縁の変形 | トレイのがた/外れ | SUSブッシュ、輸送時は拘束ネジ+固定材 |
| 吊りピンのゆるみ | トレイ落下 | ネジロック、点検 |
| アンビリカルの断線(引き出し時) | 画面が映らない | 余長100mm、ロック式コネクタ、番号タグ |
| PE編組の外し忘れ復旧 | 接地喪失 | 色タグ+復旧チェックリスト(service-manual) |
## 6. 未確認
PEM雌ねじの引抜き耐力(U29)、実機でのトレイ引き出し空間(GPU/ホースとの干渉)、アンビリカルの実長。
