| 資料 | 内容 |
|---|---|
| `00_見積依頼書.pdf / .md / .html` | ロット3段階(試作1/小ロット10/量産100)、共通条件(秘密保持/納品/梱包/検査/納期/回答様式)、見積区分A〜E、CP番号なし付帯品、購入品(型番/単価/出典/確度)、DFM確認事項、未確定事項 |

| `03_STEP/` | スタンド系特注部品のSTEP(CP-10 足、CP-20 ステータ、CP-21 ロータ、CP-22a〜e ネック、CP-23 レバー) |

## 含まれないもの(正直な範囲)
- ドーム・背板・トレイ・ガラスの**STEP**(外形はDXFと図面。曲面は貴社DFM後に作成)。
- 展開図/曲げ線、正式なGD&T、疲労・FEA、ばね/軸受の型番と実測特性。
- 内部の市販部品(CPU/GPU/基板等)は対象外(BOMは参考)。
